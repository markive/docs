Sometimes a document is no longer valid to a form as time progresses. Alternatively, a form may have the incorrect documents attached to it.  
  
****What To Do In This Circumstance?****

  
You can unlink the unwanted documents from the issue/defect/record. Please note that when this is done, it will not be removed/deleted due to data dignity. The user is still able to download the unlinked document from history.  
  
_**You will not be able to unlink the documents to the issue/defect/record when it is at closed status.**_ _Or sometimes, edit documents are only available at certain status. It depends on the settings._  
  
Ho to unlink a document:

  

Simply press the Menu icon ≡ in the top left corner of your screen to unfold the Menu and gain access to the Issue page by selecting the category and subcategory as shown below.

  

Click the **≡** button to expand the menu and select **Links.**

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/w1TH9v3Oi6CWJXoOSlcItNWSUJPNIHhLvg.jpeg)

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/sW6jhgECqE87a9TzAMtctflAXsEEUyYxug.jpeg)

  

Any items that are linked to the issue/defect/record will then be shown in a window in the centre of your screen. Simply select the relevant linked item and press "**EDIT**" as below.

  
  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/pSCNEKwJiZ3uOF-78-Gdn9_QkDdpibdsoQ.jpeg)

  

For the purposes of this example, we will select the linked attribute titled "**Documents**" as highlighted below.

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/2vZtpTmL5CGDR6SJukmhMbODhIlCzqiHwg.png)

To remove a linked document, simply click on it.

  

If you have multiple linked documents, you can press the "**Select all**" icon to select all if necessary. There is also a "**Deselect all**" icon, please note the icons below for clarity.

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/kcWApxDCXvFyTR1F1dueT9zlSxjXBMrB2Q.png)

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/bPMnhoCRf35udSyKfgxqRSbKBAGlROo2Xg.jpeg)

  

You should no longer see a grey background for the item once selected. Then you simply press "**DONE**" which will prompt the confirmation window to open as below. Press "**DELETE**" and the item will be unlinked from the issue/defect/record. 

.

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/dymGM-wafQpNcs3fOKBibDZBdRC-YPAkVw.jpeg)

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/toLAGE1B0q4Wk9lZzdDsRbZ5qFsv530QzA.jpeg)

  

The document is no longer linked to the issue/defect/record.

  

You can now see the quantity of the document is updated in the highlighted area below. To finish, simply press "**OK**" to save and complete.

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/HWwzLJHxfRAvyVSTY9egsK5LatkrR-FIJw.png)

  

All done! The item is no longer linked to the issue/defect/record!

  

![Remove attached documents from an issue/defect/record.](/images/kb/103000035023/WEtg3EJA0AZgcCzxjOlrygpwu_v4SbEVQA.jpeg)
