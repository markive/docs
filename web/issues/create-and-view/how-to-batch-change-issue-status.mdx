### **Overview**

_How to mass change the status of issues using the desktop/website_

-   **Purpose:** How to change the status of multiple items at the same time
-   **Who It’s For:** General users

<Note>
Prerequisites: Able to change the status of the issues in the selection to batch change.
</Note>

  

* * *

## **Please note: batch changing the status is a one way action and cannot be undone or reversed. If mistakes are made when changing statuses on batch would need to be corrected manually.**

##   
**From the Issue finder**

  
Press the Menu icon ≡ on the top left corner to unfold the Menu and gain access to the Issue page by selecting the category and subcategory as shown below.   
![How to batch change issue status?](/images/kb/103000390987/DAWdx65f_JyJRcjL_iYUqt--3_NFXjDvUA.png)

All issues/defects/records belonging to the subcategory will be listed on the left-hand side of your screen as shown below, select the category required, we will select **Defects** in this example.

  

![How to batch change issue status?](/images/kb/103000390987/8DuLo_rBxzbgO2wo4b_HizFgimQxVf4-qg.png)  

## To filter your data and refine your search results, there are a number of filter options available to help display the items you need, this can be the unique Issue ID as used in the example below, status, location and more. 

  

![How to batch change issue status?](/images/kb/103000390987/TMwTxSpH8nuNPUR0DR5Yb3D0XtHmmEMSHg.png)

  

From the Issue finder, select "**Browse**" in the top left and choose "**Select**" from the drop down menu.

  
![How to batch change issue status?](/images/kb/103000390987/1GmJTZmJIUUGO-tqThLCCArOnp-y88qA6Q.png)  
You can now select any and all issues you wish to change the status of by clicking from the panel on the left side.

![How to batch change issue status?](/images/kb/103000390987/xI9ZtcvIuBpB7rmMpaoCkaLyTwTyCO5q1A.png)

  

From the control bar at the top left you have the option to select all, de-select all to quickly select all items displayed:

  

![How to batch change issue status?](/images/kb/103000390987/GIzRJXbRXOd2pSyaO6UglGAabcvEKh9s7A.png)

  

Once you have the selected items highlighted you can then select "**Batch change status**".

  

![How to batch change issue status?](/images/kb/103000390987/Y4ZuKQaFD-GI_YAihJ1pdfj4NURSCBFHAA.png)

  

This will then open the "**Batch change status**" window, select the issue type you wish to change from the window.  
![How to batch change issue status?](/images/kb/103000390987/20TAKSnXjWz7gxPMDFHvA8YIiqtrjvanGg.png)

  

From here select "**Unchanged**" to select which status you want to change these issues too.

![How to batch change issue status?](/images/kb/103000390987/ZzMfWSsHG3BxNEhA2uDgmhRoBEtqdYldLQ.png)

  

From the dropdown select the status you wish to change this too:

  

![How to batch change issue status?](/images/kb/103000390987/v9GB_vxrjlxIBm7RahNpWubg_vQO3_hhiw.png)

  

Once you have selected the status you wish to change to select "**Done**".

  

![How to batch change issue status?](/images/kb/103000390987/L2GX8oaccjhtWjAtPejoxPfquswKqR78lg.png).

From here select "**Next**".  

  
![How to batch change issue status?](/images/kb/103000390987/qU1AOQT713Jg8_QOffbX9vye7nGaCDpi6g.png)

  

Add any notes about the batch change as needed and select "**OK**".

  

![How to batch change issue status?](/images/kb/103000390987/pQOUaYT7TqQxEOwTIUkszy_Mc_fDQlU2eA.png)

  

This will then initiate the batch change moving all items selected to the chosen status, you can review the progress from the batch change button in the top right.

  

![How to batch change issue status?](/images/kb/103000390987/13JHuvhEIWHsr0wmvJjLlOsQjpfiOl_xOw.png)

  

Clicking here will then show the percentage change of the issues.

  

![How to batch change issue status?](/images/kb/103000390987/Oxed5ESSktcGXQjsj5zSgyPSJlkXzdsQnA.png)
