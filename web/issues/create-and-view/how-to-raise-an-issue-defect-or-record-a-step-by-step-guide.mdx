### **Overview**

_How to raise an issue, defect or record using RDrive using the desktop/browser_

-   **Purpose:** How to raise an issue, defect or record against a location on the desktop
-   **Who It’s For:** General users

<Note>
Prerequisites: Able to raise an issue, defect or record from the desktop/browser
</Note>

## Step-by-Step Instructions - Desktop

### ✅ Step 1: Accessing the Plan Viewer

1.  From the main menu on the desktop, select "Plan Viewer".![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/HB6TyS2yrZBwvdFeMGR59hoebHeHEBLlFw.png)
2.  Navigate to the required drawing using the drilldown buttons as required.
3.  Once your required drawing or floor is open, you should now see blue "Location Pins", all actions are raised against locations within a drawing. Click the blue pin required to get started raising actions to that location.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/HbKGY4GpjFw7kLjwN5n8jwaiLxHAeYjBIA.png)

### ✅ Step 2: Raising Actions Against a Location

1.  Selecting a location will open the "Location details" window, allowing you to add actions to this location. Select the "+" button in the top right of the window.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/ACxQhuWByNt5_HHr3iAqdzRLej8jk-DArA.png)
2.  Select the required action from the appropriate subcategory, typically a defect or a form.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/QN5ylzpAL7q1hm1aEaNqSgEt06IAmHzY_Q.png)

### ✅ Step 3: Placing the Pin on the Drawing

1.  You can now place the pin against the location selected, click where you wish to place the pin and select "Place" once in the correct position.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/Cm4eG6XfAL3la-jTt1rlJNsCxknQ_5m42w.png)
2.  You can zoom and adjust the drawing on screen by turning the scroll wheel on the screen to adjust as required.

### ✅ Step 4: Enter the Action Information

1.  We can now fill out the action details. For defects, this will be categorising the issue with the option to add photos. For forms, this will be bespoke to the digital form process itself. Fields marked with a \* are mandatory to complete before moving on.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/g7k9-V3LfSkeNIwvDFvI31sWHynuCiw9KA.png)
2.  Once all mandatory fields are completed, select "OK" in the bottom right. The defect or form will now be added against the location on the drawing.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/Tncd8zVJ49LdQySK3cI3GHttu2anbPKMMQ.png)

## Step-by-Step Instructions - App & Desktop

### ✅ Step 1: Accessing the Plan Viewer

1.  Open the Plan Viewer from either the app or the desktop.
2.  Navigate to the required drawing using the drilldown buttons as required.
3.  Once your required drawing is open, click the "+" button in the bottom right corner.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/enXqtziv5-bfm4ry0SrojmaLKnBJsnP1Yw.png)

### ✅ Step 2: Selecting the Location to Raise Action Against

1.  Select the required action from the appropriate subcategory, a defect or a form for example.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/BPn9EjI8HDzslqverPCmcoZLM9GXg3jXQw.png)
2.  Select a location on the drawing you want to raise this action type against.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/J2fJGcbOXjr6zTEYED-GiyKo4jt6Ie9gzg.png)

### ✅ Step 3: Placing the Pin on the Drawing

1.  You can now place the pin against the location selected, drag or press where to place the pin and select "Place" once in the correct position.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/pLn5x3R-S0_FM4lfI8033ZLr6xwQIn-Yxw.png)
2.  You can zoom and adjust the drawing on screen by pinching two fingers on screen to adjust size as required, or using the scroll wheel when using a desktop.

### ✅ Step 4: Enter the Action Information

1.  We can now fill out the action details. For defects, this will be categorising the issue with the option to add photos, for forms, this will be bespoke to the digital form process itself. Fields marked with a \* are mandatory to complete before moving on.
2.  Once all mandatory fields are completed, select "Ok" in the bottom right. The defect or form will now be added against the location on the drawing.![How to Raise an Issue, Defect, or Record: A Step-by-Step Guide](/images/kb/103000035222/OzMS5ITHKqME4JxXFW6mDQBRSsCZ1U0sdw.png)

## ****FAQs & Troubleshooting****

**Q: How do I raise a defect or form in RDrive?**  
**A:** Open the **Plan Viewer** (app or desktop), navigate to a drawing, and select a **location pin** or tap the **"+" button**. Choose an action (defect/form), place the pin, complete required fields (\*), and hit **"Save"**.

**Q: Can I reuse info from a previous defect or form?**  
**A:** Yes. On the app, select **"Yes"** when prompted to prepopulate from the last item. Or, tap the **pen icon** in "Add Defects" to copy from an older item. Adjust fields as needed before saving.

**Q: Should I use the pin or the "+" button to raise an issue?**  
**A:** Use a **pin** if it’s already on the drawing for that location. Use the **"+" button** to place a new pin manually. Both lead to the same action entry process.
