### **Overview**

_How to delete an issue, defect or record using RDrive_

-   **Purpose:** How to delete an issue/defect/record while using the desktop version
-   **Who It’s For:** General users

<Note>
Prerequisites: Project admin
</Note>

  

The ability to delete an issue/defect/record is dependent on the permissions which are set up by the project admin.

Normally, **only** project administrators can delete an issue/defect/record.  
  
 _**⚠️ Beware!: Once you have deleted the item, you will not be able to undo it.**_ 

  

**Via Issue Finder**

  

Simply press the Menu icon ≡ in the top left corner of your screen to unfold the Menu and gain access to the Issue page by selecting the category and subcategory as shown below.

  

![How to delete an issue/defect/record](/images/kb/103000035186/lNyNmLOwb8FzksqOwJAZ88ONRp1x4AXkZg.png)

  

![How to delete an issue/defect/record](/images/kb/103000035186/DkTTRnbnX4fjam_mzwnbjRgFUAcnZj6byA.png)

  

Select the relevant issue/defect/record from the list on the left-hand side of your screen.

  

Select the issue then click the Menu icon **≡** button on the right-hand side of your screen to expand the menu.

  

![How to delete an issue/defect/record](/images/kb/103000035186/24BMh7WFqCDJ_6yqG-q8zNgO1c_8zpPZmA.png)

  

Select **Delete**, this will then bring up the confirmation window, this prevents data being deleted by accident.

  

![How to delete an issue/defect/record](/images/kb/103000035186/7V6hFwO6nL-RVgsJ8XBXk2oFcF5Uizq4gQ.png)

You will then need to confirm you wish to delete this item by clicking "**Delete**" again.

![How to delete an issue/defect/record](/images/kb/103000035186/reepPq1RJe9_6hJKFfmsyCqlVenXddtACA.png)

  

**Via Plan Viewer**

  

Press the Menu icon ≡ in the top left corner of your screen to unfold the Menu and access the Plan viewer. Then navigate to the required drawing.

  

![How to delete an issue/defect/record](/images/kb/103000035186/s7PVd3mkCOmZLuFJnOaMXbvX-ElDCvxxHA.png)

  

![How to delete an issue/defect/record](/images/kb/103000035186/-n7lNW3eYfnraDUqoikELk3ie_my4A7hQQ.png)

  

Click on the issue/defect/record pin to select this. 

  

![How to delete an issue/defect/record](/images/kb/103000035186/HKEgXljLdF-EepnMUc0qgyCRqyj2xB4Hhg.png)

  

The item details will then display on the left-hand side of your screen. 

Now press the Menu **⋮** button as shown below to expand the item menu.

  

![How to delete an issue/defect/record](/images/kb/103000035186/QzwkNEpp36iF3eWR886eCa9_36r8aCQLCA.png)

  

  

When the menu has expanded, Select "**Delete"**, this will then bring up the confirmation window, this prevents data being deleted by accident.

  

![How to delete an issue/defect/record](/images/kb/103000035186/pdOnYAWfz5Pui6uCZdkU4fIUXpUm_IEL0A.png)

You will then need to confirm you wish to delete this item by clicking "**Delete**" again.

  

![How to delete an issue/defect/record](/images/kb/103000035186/gwRG0TeIgJRaaYZn4GomQdP_SdbgUNXAiA.png)
