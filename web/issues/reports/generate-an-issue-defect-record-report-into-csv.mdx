## **To Batch Download**

  

To download a batch of multiple issues/defects/records, you must first switch the mode from "**Browse**" to "**Select**" as shown below. 

In "**Select**" mode, you can select multiple issues to export the report as necessary.

  

  

![Generate an issue/defect/record report into CSV](/images/kb/103000035111/q7WlQvyIOOFV_mqoxRQfJBwfV0SkiYlFfw.jpg)

  

  

You can also refine your download by filtering and searching for relevant issues/defects/records, which can be done via the search bar at the top of your screen as shown below.

  

  

![Generate an issue/defect/record report into CSV](/images/kb/103000035111/E5MJS-FO1LQSViw0iiM4De2XwgO1qqXxEA.jpg)

  

  

Select the desired issue(s)/defect(s)/record(s) on the left, they will be highlighted in grey as shown below. Once you are happy with the issues/defects/records selected, click the "**Download**" button highlighted below.

  
If you wish to batch download **all** the issues/defects/records listed on the left. It can be done by clicking the "**S****elect All**" button circled below (left) next to the "**Download**" button.

  

Clicking the "**D****eselect All**" button circled below (right) will clear all selected items.

  

![Generate an issue/defect/record report into CSV](/images/kb/103000035111/cZBt4dtZpKiUSdClT-81d8LaO_OBNRAuVg.png)

  

After clicking "**Download"**, the download options will pop-up as below.

  

Simply click "**CSV**"and select the Data Export Template you want and click "**Download**" as circled below to complete the report export. 

  

![Generate an issue/defect/record report into CSV](/images/kb/103000035111/mnd7bhKFMTo3urlU3Ed75zlrCiFSBUAI4g.png)
