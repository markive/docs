### **Overview**

_A brief introduction explaining the purpose of this guide._

-   **Purpose:** How to update the external reference of a process
-   **Who It’s For:** General users

<Note>
Prerequisites: Able to read and edit the item.
</Note>

  

  

  
You can update the external reference (Ext ref) of a process in RDrive. Here’s how to do it:  
  

**_Important:_** _Not everyone has permission to edit a process’s external reference. If you're unable to perform this action, please contact your project administrator for assistance._  
  
**Via Finder**

1.  Once you find the process, click the three dots (**⋮**) to open the dropdown menu.![Updating the External Reference of a Process](/images/kb/103000313171/nkfIYDSSdXf8D1zGILiWjPyL_0AiQbWo9w.png)  
    
2.  Click "**Edit**" to reveal the options.![Updating the External Reference of a Process](/images/kb/103000313171/pigyqsxcA1zvnmbYSURJiVA0toIMfPDPJw.png)
    
3.  In the expanded menu, Edit or input the external ref. and click **OK**_![Updating the External Reference of a Process](/images/kb/103000313171/DfzPywhaHdbvO-dHc_JpBLSzi5wtXXTDeg.png)_  
      
      
    _Your process ext ref has now been successfully updated!__![Updating the External Reference of a Process](/images/kb/103000313171/ZRpV6ZpI9bLArMT__TNVBPAAMS49tSvkJg.png)_  
      
    **FAQs & Troubleshooting**  
    **Q: Can I change the reference of the same item more then once?**  
    **A:** Yes, you can change the same items reference multiple times.  
    **Q: Will an external reference show on the process itself?**  
    **A:** No, this is just an external reference for you and the team and will only show within RDrive.
