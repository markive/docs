You can update the external reference (Ext ref) of a process in RDrive. Here’s how to do it:  
  

**_Important:_** _Not everyone has permission to edit a process’s external reference. If you're unable to perform this action, please contact your project administrator for assistance._

* * *

##   
**Via Finder**

1.  To locate the relevant process, apply filters using the unified search bar at the top of your screen.![Updating the External Reference of a Process](/images/kb/103000313171/Hns4qPNIPinTQL4Ff0-c2MKt58JC-fNimA.jpeg)
    
2.  Once you find the process, click the three dots (**⋮**) to open the dropdown menu.![Updating the External Reference of a Process](/images/kb/103000313171/nT_zy76QQcXluVvKjoubRL0zk6YUvUJlxA.jpeg)
    
3.  Click "**Edit**" to reveal the options.![Updating the External Reference of a Process](/images/kb/103000313171/XehFC1BCRQ8X9nePV0RWgWv9zhKBpg294Q.jpeg)
    
4.  In the expanded menu, Edit or input the external ref. and click **OK**_![Updating the External Reference of a Process](/images/kb/103000313171/dzXHPvT2F6UgFaqx23T9r8O60xsuOQjtyg.jpeg)_  
      
    
    _Your process ext ref has now been successfully updated!![Updating the External Reference of a Process](/images/kb/103000313171/brdSFnYryJqf4vkBMkwubd2u8kFShImeYg.jpeg)_
