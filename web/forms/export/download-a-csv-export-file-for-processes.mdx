Data export is a tool for general users to extract data to a CSV file for any purpose.

Please contact the company admin to request a template if needed as it is fully customised.

Let's go through how to download the CSV file with the data export template.

Please ensure that you are in "**SELECT**" mode from the drop-down options on the upper-left hand side of your screen as circled below.

You will see there are two icons at the top right corner for "**Select all**" or "**Deselect all**". These are shown below for clarity.

![Download a CSV export file for processes.](/images/kb/103000035056/RuKRnac4OW4Gz1GKVV2c3oUYElexsXQ-zQ.png)

![Download a CSV export file for processes.](/images/kb/103000035056/0atoIXvwbQTsQ8IIBON6q6I_G_liAa97Iw.png)

Click the "**Select all**" icon and then click the **Download** icon circled below.

![Download a CSV export file for processes.](/images/kb/103000035056/EGgxKtgCw7sNHLaABcAvQT1DGYhaypOuuA.jpeg)

Click **CSV** on the batch download Menu options to choose a data export template. 

If no template is available, please contact your Company/Project Admin Team to set this up.

![Download a CSV export file for processes.](/images/kb/103000035056/sXAr6QvwverFYVrDfXMYqFckirWIReM0FQ.jpeg)

Select your download preference from the list and press "**DOWNLOAD**" to confirm.

![Download a CSV export file for processes.](/images/kb/103000035056/OuN-m5LM1TnAPNBH75Y3LA26BFOR5yNQJQ.jpeg)
