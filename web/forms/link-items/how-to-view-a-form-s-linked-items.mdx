In order to view a forms linked items you must first gain access to the form viewer page by selecting the relevant category and subcategory. 

  

Once in the form viewer, simply press the 3 dots ⋮ icon to explore the dropdown menu and select "**Links**" via the view option in the Menu as shown below.

  

![How to view a Form's Linked items](/images/kb/103000035021/HsgTt6OLXbmYQ2jL0wTFw-mPv4NA-WOgVg.jpeg)

![How to view a Form's Linked items](/images/kb/103000035021/JHexZLderiyqSpATQqunrMHomrgCK5ENug.png)

  

  

All the link fields of this form will be listed by the field title for your selection as shown below. Now simply select the relevant documentation as required.

  

(Please note that this page would be skipped if there is only one link field on the form)

  

![How to view a Form's Linked items](/images/kb/103000035021/Ck-eb9bC-n9Kt6nprFH9yIuPhaqOwRVNdg.jpeg)

  

Choose the relevant **Links** from the available categories and subcategories and press "**EDIT**" to open the resulting options window as shown below.

  

![How to view a Form's Linked items](/images/kb/103000035021/l_oOw7r2B0AE09uxfO_e-TrGGigVBvfbGw.png)

  

The linked items will be presented with the latest information. 

To look into this further, simply press on the item to access on the Plan Viewer.

  

![How to view a Form's Linked items](/images/kb/103000035021/BYIiMq2bYkqLqVL0bNpomD4R4TxOb4yTpA.jpeg)

![How to view a Form's Linked items](/images/kb/103000035021/AvT0UVQ-ir7dTKy-JUp5P-Wyq87xVKMZYw.jpeg)
