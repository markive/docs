It is common that different supporting documents come along with the form itself. 

  

**RDrive** allows you to attach document(s) to a form. If you are already working on a form, and have to attach documents here's how you can do it:

  
**(You will not be able to attach any documents to the form when it is at closed status)**

  

Gain access to the form viewer page by selecting your category and subcategory. Once you are in the form viewer, simply press the 3 dots **⋮** icon to explore the dropdown menu and select "**Links**" via the view option in the Menu as shown below**.**

  

![Can I attach documents to a form?](/images/kb/103000035213/w_-vx3SiyYEpm9lTiCzebguEXji8OAc75Q.jpeg)

![Can I attach documents to a form?](/images/kb/103000035213/hUiBRPJY8N-cfhXoaxPguF0ejXutU-Fn5w.png)

  

All the link fields of this form will be listed by the field title for your selection as shown below. Now simply select the relevant documentation as required.

  

(Please note that this page would be skipped if there is only one link field on the form)

  

![Can I attach documents to a form?](/images/kb/103000035213/cOsLsR_OwJCf6hC4iue90EV8ssbIyyA-EQ.jpeg)

  

The linked items will now be shown if any are available, for the purposes of this example none are available. Now simply press "**EDIT**" to edit.

  

![Can I attach documents to a form?](/images/kb/103000035213/ygGnO8OxXFo04_gUbuk_7-co3qWg3GTcXw.jpeg)

  

Now you need to select the relevant link attribute, for the purpose of this example, we will select "**Documents**" and press "**OK**" to confirm your selection.

  

![Can I attach documents to a form?](/images/kb/103000035213/AEv-9xm3ExZLxFM2UACFl-fPfTBYaBXhfA.jpeg)

  

**Upload the document(s) from your desktop.**

  

In **RDrive**, you can upload any documents with no file type and size limit!

  

![Can I attach documents to a form?](/images/kb/103000035213/mdmPz3z8Inpap-rZ0YHHFsqhgLId5fZR0Q.jpeg)

  

The uploaded document(s) highlighted in the grey background below are **active** linked documents. 

Once you have selected the relevant documentation, simply press "**DONE**" to confirm.

  

![Can I attach documents to a form?](/images/kb/103000035213/-Uu5YtTdK6Imn5XNS8CnNNt40FkqEIe4kw.jpeg)

  

Your documentation is now added. 

You will see confirmation of this in the Edit Link window as shown highlighted below, as you can see 1 document is now uploaded. Now you can simply press "**OK**" to save your work.

  

![Can I attach documents to a form?](/images/kb/103000035213/wxqQAHZwyy5HgF8mGVSA5SuGGYWR0Mptpw.png)

  

Pressing outside of the Link window or pressing the Esc key will close your action.

![Can I attach documents to a form?](/images/kb/103000035213/Fh0uQX3c3nNn3QNjllh2OTPit43H6DQAgg.jpeg)
