**RDrive** is a location based system. You have to access a drawing and look for a location pin to add a new process/checklist record.

Simply press the Menu icon ≡ in the top left corner of your screen to unfold the Menu and choose Plan Viewer. Then you select the correct drawing.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/8pU1yFfo44uEE_WPWG4iMAcLL4ElwBlj0A.jpeg)

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/y2rcFpDi7IDG-egyLbY0l6yEJRYAO2K2QQ.jpeg)

Once you have selected your drawing, you can then create a new process/checklist.

## **Raising a process/checklist from a location**

Click on the blue location pin as shown below.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/t6EyEI3EEGwY5RosKR8OXcWKdaMKeb8t7A.jpeg)

Click the ✚ button in the top left corner for the categories list to unfold and select the subcategory which you want to create as below...

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/rqq_CBZpjUucfzQYqlR2XhRnyj3k7cLGZQ.jpeg)

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/hPF3CB-FQcCYA3D4l4S1vDruX34r4YzsBw.jpeg)

Choose the relevant process/checklist from the subcategory and enter External Reference (highlighted) information if necessary in the detail window as shown below. 

Once completed, press "**OK**" to confirm.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/FAw05rt9bCc2mehT5PcLX_K_smTELpjKrg.png)

* * *

## **Raising a process/checklist from the "add item" option**

Press the ✚ button at the bottom right corner.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/S-1sSi-bN5NGWUj2XWiPFXgxfGZB6cZp-w.jpeg)

Under the Item section, select a subcategory from the categories list as shown below.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/xrL4TiUE5KWOY6LS_rTk3K2jmZi7FBsG4A.jpeg)

You will then need to pick the blue location pin in the area you wish to raise your process/checklist.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/dxGWA-8Hh3VaJU0X55abqBrMQPre0IPe2w.jpeg)

Choose Profile from the subcategory, enter External reference information if necessary and press "**OK"** to confirm.

![How to add a Process/Checklist from the Plan Viewer?](/images/kb/103000035217/iQIijOtr4VDd-8GGDsF4COTJvUmJohbS_w.jpeg)

* * *

**Can't see the process you want to add?** 

It may be the case that you do not have the permission to create that process/checklist. Please reach out to your Project Administrator for more details.
