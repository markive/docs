If you wish to create more folders to keep documents organized, here is what you can do:

Click the menu icon **≡** on the top left corner to unfold the Menu, get entry to the **Documents** page.

![How to create a folder?](/images/kb/103000035036/urxOY7Y17_YN1DPfDRqjf-6Xd3m0YiMvOQ.jpeg)

![How to create a folder?](/images/kb/103000035036/UHnxeEmRJudi8yDIq_dHVQoCDDxSs43GKQ.jpeg)

![How to create a folder?](/images/kb/103000035036/-6L7M4SSgRMsrcoZIqt7qfHwORTFH8tcSw.jpeg)

Click **ADD FOLDER.**

![How to create a folder?](/images/kb/103000035036/c0MrUYEPN-XF10p4JJ5dXfNfN5v3S08RgQ.jpeg)

Enter the folder name and click **ADD** to confirm.  
**CANCEL** to cancel action.

![How to create a folder?](/images/kb/103000035036/nO_YoCJK_Aia7bHbdrsxkNyS_JtMKCohZw.jpeg)

DONE.

  
_✨Tips: As the path of folder name have to be unique, error msg "Error: Folder already exists" may pop up to warn you the folder with that name can not be added, please add more characters to identify your folder and make it work :)._
