RDrive can help save all versions of files and view update history as files and drawings are modified, ensuring that users can use the latest version.  
  
For example, if you have a new version of a drawing, you need to replace it so that the user does not refer to the old drawing.  
Therefore if you upload a new file to the same location with the same title within the Documents, the old file will be replaced.

The user can also check the history of file upload/replacement files.

## How to check the version history?

Left-click on the document you want to check.

![Is there version control in RDrive documents?](/images/kb/103000035039/PxWIajU7uF_lz7q79T4FykueJpKGVDiz-A.jpeg)

You could see the **Document version** at the top.

![Is there version control in RDrive documents?](/images/kb/103000035039/IFdPFryaz7aDv2cN7eVzr75lazB-uuDErQ.jpeg)

Click to select the version uploaded DateTime.

![Is there version control in RDrive documents?](/images/kb/103000035039/ztEI-6bD_qdLn1hv-uUJVbPg_IvqDjSvqQ.jpeg)

The old version will be shown and available to download.
