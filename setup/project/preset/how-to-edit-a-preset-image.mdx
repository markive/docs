Preset image is the read-only image on the form/issue. Usually will be set up from the project beginning.  
  
**Editing the preset image on the project level**  
Project admin/users with edit Preset permission can [make changes on top of the preset image](#make-changes-on-top-of-the-preset-image)that is set on the company level or [reset images to default](#reset-to-the-default-value) to fit the project needs specifically.

* * *

Click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Presets** page.

![How to edit a preset image?](/images/kb/103000035154/On4ueOAkiVR9hQvPMFsvLWgI8zaBSTwmrQ.jpeg)

Click "**IMAGE**"

![How to edit a preset image?](/images/kb/103000035154/_fu5e0dANw73k84mT2HJnOVMiN3lmKAb6A.jpeg)

* * *

## **Make changes on top of the preset image**

Click on the image that you would like to edit.  
Upload a project specific image and click "**OK**" to save

![How to edit a preset image?](/images/kb/103000035154/825zABTGoAmxzIxBB9C0B_I7Ul7i1M9Kkg.jpeg)

![How to edit a preset image?](/images/kb/103000035154/f09Y7i3NhRJlYnCT-Qx_73yBSWBIA2_lgQ.jpeg)

## **Reset to the default value**

<Info>
Can I reset the preset image to the company level setting?

Yes, you can.
</Info>

  
Simply click on the preset image and click the **RESET** to restore the image.

![How to edit a preset image?](/images/kb/103000035154/mErghjWbIOT2akLbexcfLJ8wv0bUm0SccA.jpeg)

**CONFIRM** to reset to default
