Preset text is the read-only text on the form/issue. Usually will be set up from the project beginning.

**Editing the preset text on project level**

Project admin/users with edit Preset permission can [make changes on top of the preset texts](#make-changes-on-top-of-the-preset-texts) that are set on the company level or [reset values to default](#reset-to-the-default-value) to fit the project needs specifically.

Click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Presets** page.

![How to edit a preset text?](/images/kb/103000035107/iBFnDYjNPYDgT7it52etIbGqC58zYVpk0Q.jpeg)

![How to edit a preset text?](/images/kb/103000035107/68jw2w1tl13_DL0JUsVfING61b8foTVtNw.jpeg)

All items are shown under the **TEXT** category.

![How to edit a preset text?](/images/kb/103000035107/HnxXz0QBJSyRMO7PcQMcV8eU5nm0GdJGSA.jpeg)

* * *

### **Make changes on top of the preset texts**

Click on the text for editing.

![How to edit a preset text?](/images/kb/103000035107/HZ7Ww34u5ebkmM_fQoV7CJ5s1ucHgMBfcg.jpeg)

Click on the arrow button to **undo** if need

![How to edit a preset text?](/images/kb/103000035107/w5dHkMaEeUucTZTIz_zEAs2OkQByWmq-cQ.png)

or  
Click on the blank space to confirm and save.

![How to edit a preset text?](/images/kb/103000035107/Y0RHkkGX7Ae0ebPoNN2HKA8drOAw3b8Grw.jpeg)

* * *

## **Reset to the default value**

<Info>
Can I reset the preset text to the company level setting?

Yes, you can.
</Info>

  
Simply click on the value and click the **reset** button.

![How to edit a preset text?](/images/kb/103000035107/w5uVhNdl3XxWLgYv6ey28COSFfO6fXypkA.jpeg)

**CONFIRM** to reset to default
