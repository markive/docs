From time to time, there may be some updates on list items of a preset list.  
  
**Editing the list items on project level**  
Project admin/users with edit Preset permission can [make changes on top of the preset list](#make-changes-on-top-of-the-preset-list) that are set on the company level or [reset values to default](#reset-to-the-default-value) to fit the project needs specifically.

* * *

Click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Presets** page.

![How to edit the items of a preset list?](/images/kb/103000035156/kvxi-tPNxVta4hoxiR80PrUEujsDwjbDBQ.jpeg)

![How to edit the items of a preset list?](/images/kb/103000035156/QpUMW8rgDO23s1yK3bn8RpnqbnK1C-mhQg.jpeg)

All items are shown under the **LIST** category.

![How to edit the items of a preset list?](/images/kb/103000035156/ladxAv4I1E48vO-bgfQ2IsVxJxAART4AcQ.jpeg)

## Make changes on top of the preset list

To make the change, you may  
[1️⃣ edit on the website directly](#1%ef%b8%8f%e2%83%a3-to-edit-on-the-website-directly.); or  
[2️⃣ edit by reuploading the template (single](#2%ef%b8%8f%e2%83%a3%ef%b9%921%ef%b8%8f%e2%83%a3-to-edit-by-reuploading-the-template.-\(single\)) / [multiple](#2%ef%b8%8f%e2%83%a3%ef%b9%922%ef%b8%8f%e2%83%a3-to-edit-by-reuploading-the-template.-\(multiple\))).

## 1️⃣ To edit on the website directly.

Select the list that you would like to edit.

![How to edit the items of a preset list?](/images/kb/103000035156/3jhom2pjcWa0a86RpmyeeRzi-tC4BISK1g.jpeg)

Click the ⋮ button on the right-hand side of the list title > **Edit**

![How to edit the items of a preset list?](/images/kb/103000035156/tZXsb55st5ZF4HO-yJGDgwVFqf_Qo7WK1w.jpeg)

![How to edit the items of a preset list?](/images/kb/103000035156/kHiy0a14QJRH3gVfbntwG_uMVWDgG_LqZA.jpeg)

Add a new item / new tier or edit the existing list value, click "**OK**" to save

![How to edit the items of a preset list?](/images/kb/103000035156/82LFvyWr83FTFQ4jHD6rJTFE83X73G5b2g.jpeg)

![How to edit the items of a preset list?](/images/kb/103000035156/uN6G54LkrvjM_S6ejnp2X9mxy0vA-o6nWg.jpeg)

_⭐️ Tips:_   
_New Line with same align = Item of that tier;_   
_New Line with Tab ↹ = Item of next tier._

to download the list in Excel format.

## Reset to the default value

?_Can I reset the preset list to the company level setting?_  
Yes, you can.  
Simply click **RESET** from the ⋮ button at the right-hand side of the list title.

![How to edit the items of a preset list?](/images/kb/103000035156/vhiUEcJ1tDwjuPChmTpybUN775beyveINQ.jpeg)

![How to edit the items of a preset list?](/images/kb/103000035156/IgRJ8nWzHMf57ILuNp8Aigli0QVqoPclxQ.jpeg)

**CONFIRM** to reset to default
