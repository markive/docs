Sometimes, the user is unable to use the authenticated device, they need to contact their project administrator to disable the authenticated device or the user may reset on his/her own if has another authenticated device.

Here is how the project administrator resets the verification key.

**via** **Website**

To start, click the menu icon on the top left corner to unfold the Menu, Go to **Settings** > **Users**

![How can I reset the authenticated device for others?](/images/kb/103000035150/99fY6eqc8a2_wE8cL8xq--VhQeUF4xWkwQ.jpeg)

![How can I reset the authenticated device for others?](/images/kb/103000035150/vzNcHyPoq5mOcHvgvnMUNrlRvGt3LAXjRA.jpeg)

Click the **⋮** button on the right-hand side of the user and press **Change device authentication settings.**

![How can I reset the authenticated device for others?](/images/kb/103000035150/zLBgu1rQ7jiSMI14WoH6kqEvx-acZ5swXA.jpeg)

![How can I reset the authenticated device for others?](/images/kb/103000035150/L0ZhrCfTFLmcW1ryyaHTxiAtUwmXPgeVyQ.jpeg)

All the authenticated device(s) will display this dialogue.  
Click the **trash** icon to disable.
