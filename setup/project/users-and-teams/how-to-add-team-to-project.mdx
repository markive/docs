Click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Teams** page.

  

![How to add team to project?](/images/kb/103000035146/GIVtUBnqxae2cnnQCgFWb5gdkR_LFtN98A.jpeg)

![How to add team to project?](/images/kb/103000035146/MXUEIIsHQfpt-LeTQkY-kaeJQ6vgo-C-7A.jpeg)

Press **+** button to add team.

![How to add team to project?](/images/kb/103000035146/vJ_LpvvFvB-bthdtm-kRQ6KSG7Qx0-fwBA.jpeg)

Enter the Code, Name and select team profile of the new add team.  
**OK** to confirm.

![How to add team to project?](/images/kb/103000035146/JhDtsoD4OH9p7jycUkLku65L9MQ04OLjwQ.jpeg)

or you can select the exists team/disabled team from the dropdown list by clicking the "Name".

![How to add team to project?](/images/kb/103000035146/Sz2svso1jVv9m3Q5g6vrr9cjSZuMaIbpMQ.jpeg)

  

  

  

<Note>
✨ If the code is already in use, an error message will display for a reminder.
</Note>
