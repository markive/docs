click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Users** page.

![How to edit user info?](/images/kb/103000035148/uQRrXmzjWZxVJ_QF_SsCC0pCc0mWboiImQ.jpeg)

![How to edit user info?](/images/kb/103000035148/Tu1WvT5pmrUD1I89u84FN0cGtoQIY_sDyw.jpeg)

Click the **⋮** button on the right-hand side of the user detail > **Edit**.

![How to edit user info?](/images/kb/103000035148/uOY7_seaUFn8AkSKFzuT3mdxuzdeIpCdPQ.jpeg)

![How to edit user info?](/images/kb/103000035148/yVW-u7Qoo0lrtvloWieRC4TKRjIf0iUSrw.jpeg)

From here you are able to edit the user display name, email address and system language.  
Edit the info and click **OK** to save.

![How to edit user info?](/images/kb/103000035148/uczX0xu3p29yOu1pmtcKFQl-jA8it1fBGA.jpeg)
