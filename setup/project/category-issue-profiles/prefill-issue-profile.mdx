## **Prefill Functionality**

The **Prefill** feature allows you to enter data before adding a new record. The entered data will remain editable, making it easier to input and adjust information as needed.

* * *

## **How to Set Up Prefill**

To set up the **Prefill** feature in your project, follow these steps:

1.  Access the project via the website.
2.  Click the **≡** menu icon at the top left corner to open the menu.![Prefill - Issue profile](/images/kb/103000035129/rgoonxL2-z2yWbwkKQAiuZ_bh4PHtdMeGQ.png)  
      
    
3.  Navigate to **Settings > Categories** and select the appropriate category and subcategory.![Prefill - Issue profile](/images/kb/103000035129/Z04aY7yPfg5KHva6v6eKicivzj6Wr318FA.png)![Prefill - Issue profile](/images/kb/103000035129/WyA1oXb8_5F5QaGYhVnD1ge3XW07JkBbhA.png)  
      
    
4.  Select the desired profile and click the **≡** button to expand the menu.![Prefill - Issue profile](/images/kb/103000035129/wAHDerdBd8URV2k_UuUDhAmvYG-0YCo0aw.png)  
      
    
5.  Choose **Prefill** and enter the necessary data into the template as prefill values.![Prefill - Issue profile](/images/kb/103000035129/hoHNKtDVBoi3DwCHAUCVRBb8t6TUPz1L-w.png)
6.  Click **OK** to confirm and save your data.![Prefill - Issue profile](/images/kb/103000035129/TcWEuXIQPzLsyB8LzJ4EMOfSlSiKEPogGQ.png)
