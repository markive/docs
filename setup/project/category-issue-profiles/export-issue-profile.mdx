#### **To Batch download -**  
Switch mode from "**Browse**" to "**Select**".

![Export Issue profile](/images/kb/103000035127/hOdD0YimeNXR8tNufS4iK1NLwvOQ_3-OaA.jpeg)

![Export Issue profile](/images/kb/103000035127/A409o9NNsqAOS8oZ9tCtM7H88EjGpOlMXw.jpeg)

Click on the item or press the **select all** / **deselect all** button to select item(s).  
The selected item will be highlighted in grey.

![Export Issue profile](/images/kb/103000035127/IojSK-Pa5uEgWNSu_bELUMhNxeCbFqja1w.png)

Press **Download** icon to batch download.

![Export Issue profile](/images/kb/103000035127/X50Osg1NkPnIU2TKun23XEx6-dCipPuclw.jpeg)

* * *

### **To download one by one -**  
Select profile, click the **≡** button to expand the menu.  
Click **Download**.
