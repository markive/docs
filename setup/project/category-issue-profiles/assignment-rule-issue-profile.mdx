## **Issue status**

Select an issue status for the assignment rule.  
The issue will be assigned when the record updates to the selected status.

### Assign attributes

You may assign to the specified team/team's user or base on the team field and user field on the template to decide the assignee.

1️⃣ **User** - Select team and team's user to edit a rule for specifying assignee.

![Assignment rule - Issue profile](/images/kb/103000035128/_AGOib5mndE40rMeZK8rT8Rbdqdj1MB6Xw.jpeg)

2️⃣ **Field** - click **Add Field** to pick a field on the template to decide the assignee for this rule.

![Assignment rule - Issue profile](/images/kb/103000035128/PFGIjOr7p04JeCNMEofKuKwjVenBuSbNlw.jpeg)
