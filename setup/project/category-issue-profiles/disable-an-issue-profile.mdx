title: "Disable an Issue profile"
description: "Once the profile disabled, no new records can be created with this profile. Existing issues are not affected by this."
---

Once the profile disabled, no new records can be created with this profile. Existing issues are not affected by this.

? **via Website**  
You will able to see the menu icon on the top left corner, please click it to unfold the menu, access the **Settings** > **Categories**, select the category and **subcategory**.

![Disable an Issue profile](/images/kb/103000035122/iabrr0Y9kyC9n4devl9L_CtNfJ9m7Mg_XQ.jpeg)

Select profile, click the **≡** button to expand the menu.

![Disable an Issue profile](/images/kb/103000035122/RRJgZ-gNUZXdiy3KBU6ArV1eymHLrH8Ing.jpeg)

Select **Disable.**  
**Disable** to confirm.
