<Note>
Project admin may edit profile title, profile tag and ID format on the Project level.
</Note>

  

You will able to see the menu icon on the top left corner, please click it to unfold the menu, access **Settings** > **Categories**, and select the category and **subcategory**.

![Edit issue profile](/images/kb/103000035130/y9KxuFToOlbWzsbWpnkdQCn6WS_uqXnlFw.jpeg)

![Edit issue profile](/images/kb/103000035130/3EcvzsQFF2U9RJLlKeecYALPlexurqi8cw.jpeg)

![Edit issue profile](/images/kb/103000035130/lbW9nQ7_qD1ayUBp5-axesn0V4OPiWFRlg.jpeg)

Select the profile, click the **≡** button to expand the menu.

![Edit issue profile](/images/kb/103000035130/0P9xpQPJmyWwSwWhbkQf90vdv6MkBv40FA.jpeg)

Select **Edit** to edit the title, profile tag, and client ID format _(ID_ _digits)_.  
**OK** to confirm.
