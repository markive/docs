A Permission Policy forms the cornerstone of defining user rights, working collaboratively with [Team Profiles and Teams](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035145-what-is-team-profile-and-how-to-setup-) to establish access parameters.

Each permission policy can have single or multiple permission rules. If there are common permission rules, you can create a basic permission policy and re-use it by adding it as [usage](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035089-what-is-edit-usage-in-permission-policies-) to another permission policy.

* * *

## **via Website**  

1.  Click the **≡** menu icon in the top left corner to access the Menu.![How to add a permission policy?](/images/kb/103000035141/eGzXR9tJn3ET-ruWjLYliWVtuFXeLLKOGg.jpeg)
2.  Navigate to **Settings** > **Permissions**.![How to add a permission policy?](/images/kb/103000035141/Si7bnPUmJ3Df5nHEIonzzWakHEBp7RtIow.png)  
    
3.  Press the **+** button to add a new permission policy.
4.  Enter the permission policy title and click **OK** to confirm.![How to add a permission policy?](/images/kb/103000035141/OCMys7mqgbwsgSVjdswzn3p78XBWUMFZdQ.png)
5.  Afterward, click the **+** button in the bottom right corner to add rule(s).![How to add a permission policy?](/images/kb/103000035141/tous2y2X2YTBIZBEyxASqzn7p3tfFvz2cA.png)![How to add a permission policy?](/images/kb/103000035141/sZcqvT0YB615zeh1u9eU9QdUe_fXKvDR5g.jpeg)
