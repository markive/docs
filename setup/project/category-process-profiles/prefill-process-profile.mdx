## **Prefill Functionality**

The **Prefill** feature allows you to enter data before adding a new record. The entered data will remain editable, making it easier to input and adjust information as needed.

* * *

## **How to Set Up Prefill**

To set up the **Prefill** feature in your project, follow these steps:

1.  Access the project via the website.
2.  Click the **≡** menu icon at the top left corner to open the menu.![Prefill - Process profile](/images/kb/103000035121/YjnpJQPwoeS1Ij0jG5_ll2JKDlvDHKb0wQ.png)  
      
    
3.  Navigate to **Settings > Categories** and select the appropriate category and subcategory.![Prefill - Process profile](/images/kb/103000035121/ySr460XqSyZi27nqjq6AoGuQD5SkKTBaKA.png)![Prefill - Process profile](/images/kb/103000035121/DZZcpaPILVBJBJIFv1_COiPmzUmQ-c7GPw.png)  
      
    
4.  Select the **Profile**, then either click on the form or click the **Settings** button to open the form viewer page.![Prefill - Process profile](/images/kb/103000035121/ySD18roxumAs0j7W8K1uXW2LKueN-E6Wfw.png)  
      
    
5.  Enter the data in the fields as prefill values.![Prefill - Process profile](/images/kb/103000035121/yMkTUXryHDHqj0raj9EtVGHiq1mtHQD54Q.png)  
      
    
6.  The updates will be saved automatically.
