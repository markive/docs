<Note>
Project admin may edit profile title, profile tag and ID format on the Project level.
</Note>

You will able to see the menu icon on the top left corner, please click it to unfold the menu, access **Settings** > **Categories**, and select the category and **subcategory**.

![Edit Process profile](/images/kb/103000035125/AMkJQixm3NmCg4tcHt0ajXJlfHQgyzOfdA.jpeg)

![Edit Process profile](/images/kb/103000035125/rm1J9MSqF1lYoeSFlyALkV9v1nLzD3A8CA.jpeg)

![Edit Process profile](/images/kb/103000035125/Cc5zEddQIUJ3cECLpOv8VmTXYjAJs4QjBA.jpeg)

Select the profile, Click the **⋮** on the top right corner.

![Edit Process profile](/images/kb/103000035125/kYnUuoPG8lL5NPtdyBRSQB9JeWE6mxrgUA.jpeg)

  
Select **Edit** to edit the title, profile tag, and client ID format _(ID_ _digits)_.  
**OK** to confirm.
