---
title: "Why can't I edit a Process Profile's 'pre-population' fields, I see a blank page."
description: "In order to edit form fields for pre-population you will also need the 'Automation: Create + Edit + Delete' permissions for this to be available."
---

In order to edit form fields for pre-population you will **also** need the '**Automation: Create + Edit + Delete**' permissions for this to be available.

Make sure there are no options or conditions under each of these permissions as form automator requires full access to automation rules.
