# **A Comprehensive Guide to Setting Up Assignment Rules**

An Assignment Rule is a powerful feature that allows users to pre-assign data automatically when adding a new record. This ensures that the data remains editable, correctly assigned, and consistent with predefined criteria. In this guide, we'll cover how to configure and apply assignment rules effectively using the website interface.

* * *

##   
**Why Use Assignment Rules?**

Assignment rules help automate the assignment of records based on specific criteria, such as form status, attributes, or field data. They streamline workflows, ensure consistency, and reduce manual errors. Here’s a step-by-step guide on how to set up and use them.

##   
**Step 2: Configuring the Assignment Rule**

## **1\. Select Rule Operation Mode**

There are four types of rule operation modes: **ASSIGN**, **SUBSCRIBE**, **UNSUBSCRIBE**, and **CHANGE CONTROLLER**. For this guide, we’ll focus on the **ASSIGN** mode.  
![Assignment rule - Process profile](/images/kb/103000035120/THsZbH4Uc0d_Ivpcw66JoO8SSr5dIjxq0Q.png)

###   
**2\. Define the Rule Parameters**![Assignment rule - Process profile](/images/kb/103000035120/YxodNqEQGCSCrxtVin8QD1aIJqNBYnDeiQ.png)

#### **Form Status**

-   Choose a form status that will trigger the assignment rule. The rule is activated when a record updates to the chosen status.  
    ![Assignment rule - Process profile](/images/kb/103000035120/4c-YUUkCBMgcwCYKogdxhxHNx0J0eFF84Q.png)  
    

#### **Assign Attributes**

-   Assign the form to a specific team or user. This is a required setting for every assignment rule. You have three assignment options:
    -   **TEAM Assignment**: Select a team and specify the user(s) within that team.
    -   **Field-Based Assignment**: Click **Add Field** and pick a team field or team + user field from the form. This option assigns the record based on the selected field value.  
        _(Note: The rule will not be triggered if the data of selected User team and team field have no relationship.)_
    -   **[Controller](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035073-what-is-controller-and-how-to-change-)**: Assign the record to the current controller.    
        _([What is controller?](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035073-what-is-controller-and-how-to-change-))_

  
In this guide, we’ll use **TEAM** as an example, assigning the form to the entire "Management" team.**![Assignment rule - Process profile](/images/kb/103000035120/r9RlJQTItHE5y1q9W3jgv_ZTdvy8whsY0Q.png)**  

#### **Form Data (Optional Condition)**  
The Form Data optional condition allows you to add specific criteria based on field data within the form. By setting these conditions, you can further refine when the assignment rule is triggered, ensuring that records are assigned only if they meet the defined field values. This feature provides more control and flexibility in automating record assignments based on form content.

-   Add extra conditions based on field data, if desired:
    -   Click **Edit** to access the conditions.  
        ![Assignment rule - Process profile](/images/kb/103000035120/66bsgr3J-ThfGfr8FrBQfB5W5JEMFPC6fQ.png)
    -   Select **Add** to define the condition, choosing the relevant form field(s) and specifying values.  
        ![Assignment rule - Process profile](/images/kb/103000035120/0B61RnOpx9i31lbjPdUG2lPROmL0a8SYGQ.jpeg)![Assignment rule - Process profile](/images/kb/103000035120/8iLS6BjmoIw7uSssBAebXUFH-RZqN_S05g.png)![Assignment rule - Process profile](/images/kb/103000035120/C1UXTq7ComtKakjoO6xfzm_bwTBhZcHPQA.jpeg)  
        
    -   _There are operator options based on the data type, such as **contain**, **equal**, **empty**, **filled**, or **range**, which you can select if needed._  
        ![Assignment rule - Process profile](/images/kb/103000035120/6N5GlkbwrviauKDT3pKGSZ5IJjnE2SlmAA.png)  
        ![Assignment rule - Process profile](/images/kb/103000035120/D_bw7gdXesGtsqoVRCkosaXltjaN5lGXWQ.png)
    -   Click **OK** to confirm.![Assignment rule - Process profile](/images/kb/103000035120/JpRYkcNbFYW2xSAMYApf6iusdoLP4UKf1g.jpeg)

**Additional Actions: Editing or Removing Rules**

#### **To Edit a Rule**

-   Click directly on the rule, make the necessary changes, and click **OK** to save.  
    ![Assignment rule - Process profile](/images/kb/103000035120/V9ZGXjrnyMs0EokV9-Ekb2VG0JKtA0NcGA.png)![Assignment rule - Process profile](/images/kb/103000035120/FvKn4MNXjv1BqUBjZ4AD8StV8RhnJn6xAA.png)

#### **To Delete a Rule**

-   If you need to delete a rule, click the **Delete Rule** button at the bottom left of the dialog box.![Assignment rule - Process profile](/images/kb/103000035120/54HeeiWdgVJQPGCqGlRYfUPQIRNgYV4J6w.png)

Click on the blank area of the page to exit the configuration screen.
