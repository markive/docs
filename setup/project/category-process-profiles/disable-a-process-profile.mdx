title: "Disable a Process profile"

---

Once the profile disabled, no new records can be created with this profile. Existing issues are not affected by this.

? **via Website**  
You will able to see the menu icon on the top left corner, please click it to unfold the menu, access the **Settings** > **Categories**, select the category and **subcategory**.

**Disable** to confirm.
