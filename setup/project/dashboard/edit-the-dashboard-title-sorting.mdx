<Info>
The dashboards would be built and ready by the RDrive support team.
Project admin could able to edit the dashboard title and sorting.
</Info>

* * *

Click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Dashboards** page.

![Edit the dashboard title & sorting](/images/kb/103000035115/KBz26DExO-Ov-_JEiHKa1sdOViIRn9lhlA.jpeg)

![Edit the dashboard title & sorting](/images/kb/103000035115/LxEixup9LprbqmQ12tvCFqk5YusUpZgXag.jpeg)

Select the dashboard, and click on the title to edit.

or

Drag and drop the dashboard by holding down the = to sorting.

![Edit the dashboard title & sorting](/images/kb/103000035115/_x-ZqEpE-m8pcrnO-tP4ICgP8BzcytKVTA.jpeg)
