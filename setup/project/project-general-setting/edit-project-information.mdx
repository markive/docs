<Info>
As a project admin, you may have the authority to edit the project information.
</Info>

  

  

Click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Project** page.

![Edit Project information](/images/kb/103000035108/RTxDuDuKmN2y-v8mo5UA6fAEQKSIz4siuA.jpeg)

![Edit Project information](/images/kb/103000035108/CSW2v-mtKnI3gbDHkj2WAyVEHQ_202iF-w.jpeg)

Click on the "**Edit**" button to open the edit project window.

![Edit Project information](/images/kb/103000035108/Ga26VRuykaR5_cFtysZe1Rx6C0kbeSYi8Q.jpeg)

You may edit the Project logo, name, language, Time zone & tag(s) here, the update will affect the whole project.

![Edit Project information](/images/kb/103000035108/FwP4ZW-3mXBH0xya9bNVih1WI2v3OqhUgw.jpeg)
