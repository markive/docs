To edit or delete a drawing set, follow these steps:

-   [Editing a Drawing Set](#Editing-a-Drawing-Set)
-   [Deleting a Drawing Set](#Deleting-a-Drawing-Set)

####   

#### **Accessing the Drawings Page**

1.  Click the Menu icon (**≡**) in the top-left corner of your screen to expand the Menu.![How to Edit or Delete a Drawing Set?](/images/kb/103000035137/_GVf6NHB0Q4STzZVIM6GAJnwCQMmzTFEyw.png)
2.  Navigate to **Settings > Drawings**.![How to Edit or Delete a Drawing Set?](/images/kb/103000035137/Otyzg7e38PGuimZA43VfZOj8w2Pt_oBakw.png)

####   

* * *

#### **Editing a Drawing Set**

1.  Select the drawing set you want to edit.
2.  Click on the drawing set title to make your changes. ![How to Edit or Delete a Drawing Set?](/images/kb/103000035137/prAm_eQTxPWxmZH26Cy7wRK5TUIMPm0-8g.png)

####   

####   
  

* * *

#### **Deleting a Drawing Set**

####   
_Important Notes:_

-   _⚠️ All drawings must be removed from the drawing set before you can delete them._
-   _⚠️ Deleted drawings cannot be restored, so please proceed with caution._

  

1.  Click the **⋮** button on the right side of the drawing set title.![How to Edit or Delete a Drawing Set?](/images/kb/103000035137/w6VeimNIE5xuXEgKOytq5ZMxVacTZThUWg.png)
2.  Select **Delete**, then confirm the action.![How to Edit or Delete a Drawing Set?](/images/kb/103000035137/MC_y55HA2jhfVRNh-0p2nTC-tqOBoLBK1Q.png)![How to Edit or Delete a Drawing Set?](/images/kb/103000035137/vORv9g1suwespIN-QIGPHMaIY1A8zqQLew.png)
