# How to Edit Drawings in RDrive

To begin editing a drawing in RDrive, follow these steps:

1.  **Access the Settings Page:**
    -   Click the ≡ menu icon in the top left corner to unfold the Menu. Navigate to **Settings** and then select **Drawings**.![How to Edit Drawing?](/images/kb/103000035138/t_oJvPyg_eSWd0z3F1ZJcxn-5BPIs6NHVg.png)![How to Edit Drawing?](/images/kb/103000035138/CVXeKsM_sd0hj8tvoYcWruYWpblUkDvC6g.png)  
          
        
2.  **Select the Drawing to Edit:**
    -   Click the ⋮ button on the right-hand side of the drawing title, then choose **Edit**.![How to Edit Drawing?](/images/kb/103000035138/pNM1p1oh0JwokQue-19L4Df0WoMC6bT1dQ.jpeg)![How to Edit Drawing?](/images/kb/103000035138/JU4O3qDNp-Sw-XCcZHP8DJM9iis4tuv6_g.jpeg)  
        
3.  **Editing Options for a Drawing:**        **![How to Edit Drawing?](/images/kb/103000035138/PBLXCXrJ_mL4BgcjlRRvideOVvrQ0ElDLw.jpeg)**        
    -   **Title:** To change the title of the drawing displayed on your device, web, and reports, edit the **Title** field.
    -   **Drawing Set:** To change the drawing set that stores the drawing, edit the **Drawing Set** field.
    -   **Drawing Tag:** To update the drawing tag, enter or remove the tag as needed. Click **OK** to confirm your changes.
    -   **Drawing File:** To replace the existing drawing image, drag and drop a new file from the local drive or click to select a file from your device.  
          
        
4.  **Additional Menu Options:**You might be curious about the functions of other options in the menu. Here’s a brief overview of what you can do:**![How to Edit Drawing?](/images/kb/103000035138/Hr8sE6IhYNYWM4HTPK05HYy71Kd_jNqF3A.png)**  
    -   **Plan Viewer:** View the drawing in the Plan Viewer.
    -   **Download:** If you wish to change the drawing shown, it’s advisable to download the original drawing first. Click **Download** to save it locally as a backup.
    -   **Set as Default:** Make this drawing the default top-level drawing.
    -   **Clone:** Create a copy of the drawing.
    -   **Delete:** Remove the drawing from the project.  
        

> **Note:** If there are existing issues linked to the drawing, be aware that any changes made must maintain the same positioning and scale as the original. Otherwise, previously added issues may appear to shift and will not display in the correct position. It’s recommended to consult with a RDrive representative before making any alterations.  

5.  **Batch Editing Drawings:**
    -   You can batch-edit drawings from this page by changing the mode to **SELECT.**![How to Edit Drawing?](/images/kb/103000035138/KlwID8b-t3rZXb9iaX-loV0DBOwvFQpt-A.png)![How to Edit Drawing?](/images/kb/103000035138/Mezu5KrGj6gBQaMLLsiJYAw3nqO5BOxlsg.jpeg)  
        
    -   Click on the drawing you wish to select; the selected item will be highlighted in grey.  
          
        
6.  **The batch edit options will appear for your action:**  
    ![How to Edit Drawing?](/images/kb/103000035138/7-c_VDJgYrLn5CHKB36ON5K-pMKiHXPX-w.gif)
    -   **Deselect All: Deselect all drawings from the current drawing set.**
    -   **Select All:** Select all drawings from the current drawing set.
    -   **Delete Drawings:** Be cautious—deleted drawings cannot be restored.
    -   **Rotate:** To rotate a drawing, click the **Rotate** button. Each click rotates the drawing 90 degrees clockwise. Click twice for a 180-degree rotation or three times for a 90-degree counter-clockwise rotation.
    -   **Batch-Edit Drawing Tags:** Enter or remove tags for the selected drawings.

* * *

By following these steps, you can effectively manage and edit your drawings in RDrive to enhance your project organization.
