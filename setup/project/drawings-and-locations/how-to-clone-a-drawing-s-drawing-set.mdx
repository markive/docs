You can easily clone individual drawings or an entire drawing set by following the steps below. There are two main methods to clone a drawing set: manually or by using a template.

* * *

## **Cloning a Drawing Set**

There are two ways to clone a drawing set:

1.  **Manually**
2.  **Using a Template**

  

To begin, click on the **≡** menu icon at the top left corner to open the Menu, then navigate to **Settings > Drawings**.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/lZcGwAWq8U1ogBsKtxQVqpvwhVlI8mHFlA.png)![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/qVMFXJnxEhf_MtgEcUK0CnX3VOPCRGu_WA.png)

  

* * *

##   

##   

## **1\. Manually Cloning a Drawing Set**

1.  Select the desired drawing set.
2.  Click the **⋮** button on the right side of the drawing set title and select **Clone**.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/mFc_EqDks53E5rmQtHNbsTJL2_5_cQMgUQ.jpeg)![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/y744NUpPD4FuQjKUrkPpD7mmtXMuseja1A.jpeg)
3.  In the dialog box, input the number of copies you wish to create.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/0e743esn8TbPE8_PgFzI9uCAF-Z0naP00g.jpeg)
4.  Click **OK** to start the process.

* * *

  

  

  

## **2\. Cloning a Drawing Set Using a Template**

1.  Select the drawing set and click the **⋮** button on the right side of the title, then choose **Clone**.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/3UK8KViQkhDYpJ_fe66rmJgRI0_pqjlkXA.png)
2.  In the dialog box, click the **UPLOAD** button located at the bottom left corner.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/M2xdunDzd0AsnPuc2nBHUSZzRVgB3xEFCg.png)
3.  Download the provided template and fill it in with the necessary information (a sample is provided for reference).![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/_HwgSbAMiO2rWAmAqKGBzBpfG6bz1RCcAQ.png)![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/jBH_wJfNJYTsNBrqNDgtb0a5Cc4m98U1Xg.jpeg)
4.  Once the template is complete, upload the file.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/gxZbuSsd76O9yUamCdDfTNxBIyy-MH6DeA.png)
5.  The system will clone the drawings based on the data you entered in the template.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/civNEsNlIhKgZmbfahC_1iJE8Oosa191gQ.png)

## **Cloning a Single Drawing**

To clone a specific drawing within a set:

1.  Locate the drawing you want to clone.
2.  Click the **⋮** button on the right side of the drawing title and select **Clone**.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/NjM_zzdYoshwRWNCHqQt0H4jtyL-iyaTeA.png)![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/VSG0lY2UKFqxVXpAOVBlM7vUuaJkYmWWEA.jpeg)
3.  In the dialog box, click the **Add Clone** button if you need to increase the number of clones. Choose the drawing set, edit the drawing title, and click **OK** to confirm.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/vnlHHu5GfbIcEOVrWvU02qxKbbOf1Bjc2g.jpeg)
4.  The drawing will be cloned.![How to Clone a Drawing(s) / Drawing Set?](/images/kb/103000035136/nOnAh9kQRkox1ik1tMDSBmPySox9r5lXYA.jpeg)

* * *

  

This process helps streamline the duplication of drawings or drawing sets, making it easier to manage and maintain consistency across projects.
