You may edit a location pin one by one from the [Plan viewer](#h_f9a432bad4) or [Location page](#h_8be352ad81) and [batch edit](#h_77c6ada42d) the location tag and location title from the Location page - review mode.

##   
via Plan viewer -

You will able to see the menu icon on the top left corner, please click it to unfold the Menu, access the Plan viewer, and select the correct drawing.

![](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/103008861913/original/6i_7rBVzCrCTvyDlQcLlqsHaACGQF3H50w.jpeg?1673535202)

![Edit / Delete the location pin(s)](/images/kb/103000035134/OhTSv1ABEFYLosfAg_muC3DC3Kr26Ve3sQ.jpeg)

Select the location pin.

![Edit / Delete the location pin(s)](/images/kb/103000035134/g09farOViEAg_Hx11l41mzdH48vpfYdlOQ.jpeg)

Click the **⋮** on the top right corner of the location dialog.

![Edit / Delete the location pin(s)](/images/kb/103000035134/eubBYdk_tmH8tyUPg7zzSzpl5Ej_lLTwsA.jpeg)

* * *

Select **Edit** to edit the location title, ext ref & tag.  
**OK** to confirm.

![Edit / Delete the location pin(s)](/images/kb/103000035134/9KHy-R1iiqcrtG6l75hUMtbHcvJK7yDDxA.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/Y6LElUuSnWz4z5VrE5f4iBriv9xoN2Rl8A.jpeg)

* * *

Select **Move** and drag the position on the drawing.  
**OK** to confirm.

![Edit / Delete the location pin(s)](/images/kb/103000035134/GCPh7gIRgGAaCkQ3c0umd8fXhazSrIztww.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/U1tUQ_K3i1lcu9vm_8JsPQzqoVv_tkpg8w.jpeg)

* * *

Select **Delete** to delete location pin.  
**DELETE** to confirm.  
⚠️ _Beware!:_   
_You can only delete the location pin with no record attached._   
_Once you have deleted the item, you will not be able to undo it._

![Edit / Delete the location pin(s)](/images/kb/103000035134/B_79FytFGXIZcC_HXvASssMYQxIhqj9p5w.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/uw0A6pKtTJM0e4MAW09nTi3KVwfZdANGxQ.jpeg)

## via Location page -

You will able to see the menu icon on the top left corner, please click it to unfold the menu, access the Settings > Locations.

![Edit / Delete the location pin(s)](/images/kb/103000035134/5kKKHliyvdRciadSpC6ZwhujCIzm_yGQWg.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/jh_if1vLqd7miuvmZxqkkoG7vEM4EeV4sg.jpeg)

Select location. You may search to find the location from the search bar.  
Click the **≡** button to expand the menu.

![Edit / Delete the location pin(s)](/images/kb/103000035134/iP_l3TBmYx-W02uw1fRUtWS-xVHu5WD8yA.jpeg)

* * *

Select **Edit** to edit the location title, ext ref & tag.  
**OK** to confirm.

![Edit / Delete the location pin(s)](/images/kb/103000035134/Ndl_Ut55nMgMeYAvr9YbqE6fSbveOPN7AQ.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/UIVrNM06PnHCNOFhoi0duBXF0e_nNcCCng.jpeg)

* * *

Select **Delete** to delete location pin.  
**DELETE** to confirm.  
⚠️ _Beware!:_   
_You can only delete the location pin with no record attached._   
_Once you have deleted the item, you will not be able to undo it._

![Edit / Delete the location pin(s)](/images/kb/103000035134/_74RAOllYMt2h-P420GzcnCgkhSyTl9D_w.jpeg)

## Batch edit

You could batch edit the **location title** or **location tag** by find and replace from the location page.  
Let me show you how :)

Switch mode from "**Browse**" to "**Review**".

![Edit / Delete the location pin(s)](/images/kb/103000035134/8fMiqBpH4kMVW5Hnpiv8tsnuyaw4KbykWg.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/XSNFs4h4YkdeiO4uW6RCVFp2tNN_91puyg.jpeg)

* * *

You could find and replace the location title with the first button on the top right corner as below.

![Edit / Delete the location pin(s)](/images/kb/103000035134/iGvwdnRkZKi-r7NBLBzvAaxgPUDJK2-mgQ.jpeg)

![Edit / Delete the location pin(s)](/images/kb/103000035134/6-CaifyuXAjDijIkCgQYTuSBUM3WWYdW4A.jpeg)

You are able to click to change the find option to Match whole word if need.

![Edit / Delete the location pin(s)](/images/kb/103000035134/H3by7bBT0c6H0qdWTDzR6Osn5X-JC-3JJQ.png)

* * *

You could find and replace the location tag with the second button on the top right corner as below.

![Edit / Delete the location pin(s)](/images/kb/103000035134/6sFIJzSbNsUsQ9ouhc8E8Yzw9M-97-l4iQ.jpeg)

You are able to click to change the find option to Equal / Contain if need.

![Edit / Delete the location pin(s)](/images/kb/103000035134/vGX3lDOkv9wNVUBbgQ_enmmTsz6V5IBLLQ.png)
