## **What are Locations?**

Project locations help RDrive determine which area of the project each issue or process belongs to. For example, locations can represent different rooms. When an issue is added, the system knows whether it pertains to Room 01, Room 02, or Room 03. The location of an issue will appear in reports, meaning you don’t have to refer back to the drawings to identify where an issue is located.

It is best to set up all locations at the start of the project across all drawings so that issues and forms can be added to all areas. Once locations are set, additional locations typically don’t need to be added unless some were missed.

Locations can be added via the website and the app.

> **_Note_**_: If the location button is missing or you don't have permission to add locations, please contact the project admin._

## **How to Add a Location Pin via Website**

1.  **Access the Plan Viewer**: Click the **≡** menu icon at the top left corner to open the Menu.![Location pin on the drawing](/images/kb/103000035168/wKI4QlvkWIpMd8mS2ttOHn-YzdQl1hAcaA.png) Navigate to the **Plan Viewer**, and select the relevant drawing.![Location pin on the drawing](/images/kb/103000035168/wkVZWzQNeOfIGx_qrF15lo1KACUzjZlVAA.png)
2.  **Add Location Pin**: Click the **+** button at the bottom right corner of the screen. Then, select the location icon and move the pin to the desired location on the drawing.![Location pin on the drawing](/images/kb/103000035168/5wiRafyhtwqTEHCxvg-cgoSvnMTiwAXbZA.png)![Location pin on the drawing](/images/kb/103000035168/NCFbh-3tK5M-LyboTD7dBBpaNlb0TLLXrg.png)
3.  **Confirm the Location**: Enter the details for the location and click **OK** to save.![Location pin on the drawing](/images/kb/103000035168/ydWVrYW75PQthPiTtaRkWfuYUGhdpfSi7g.png)![Location pin on the drawing](/images/kb/103000035168/xohaXuet9dUcJgaQtzD-QiYtI8VRGOptkg.png)

## **How to Add a Location Pin via App**

1.  Open the app and access the drawing where you want to add the location pin.![Location pin on the drawing](/images/kb/103000035168/0UcZq37jQgUWVp3cDVyOGTNsXk9UfgsFgg.png)
2.  Click the **⋮** (three vertical dots) on the top right corner and select **Add Location**.![Location pin on the drawing](/images/kb/103000035168/wuiNnMO8HHKBS3BJWCtuYl3UmyzdukZUig.png)
3.  Drag the location pin to the desired position on the drawing, then click **Place**.![Location pin on the drawing](/images/kb/103000035168/HCIQAYsq4DQei0ykCe3AztNQsbE48LMxLg.png)
4.  Input the location title and, if needed, an external reference. Click **Save** to confirm.![Location pin on the drawing](/images/kb/103000035168/PBpfkHDdraMvkT4nV5c3qL5SUPCWzihVOw.png)

### **_What is the External Reference?_**

_An **External Reference** is an additional identifier that helps further distinguish between locations. For example, it can be used to:_

-   _Link Room Data Sheets or other external documents to specific locations._
-   _Assign different names for the same location, such as using one name from the architect and another from the construction company._

_This feature helps ensure clarity when multiple naming conventions are involved in a project._

_[What is tag?](https://docs.rdrive.io/faq/setup/how-are-tags-used)_

## **Batch Upload Locations via Website**

1.  In the **Plan Viewer**, click the **+** button in the bottom right corner, then choose **Location**.![Location pin on the drawing](/images/kb/103000035168/JFQRpqyM6wCWv8n7X4Q7lHyansDmH5DpTg.png)
2.  Click the **⋮** icon in the location dialogue to download the location template.![Location pin on the drawing](/images/kb/103000035168/V_iVw9_ShyDF9y85I6_nnRYQNo-3CSbvEQ.png)![Location pin on the drawing](/images/kb/103000035168/mk30gstxdJj9F0BK6G10XF9pW0gvIDPdbw.png)
3.  Edit the downloaded Excel file with the relevant location names.  
    
    ![Location pin on the drawing](/images/kb/103000035168/l_o7Rmu7Tz1S0D_oXbxuapAjdMHocYZ7Gw.png)
    
      
    
4.  Once done, upload the completed template to import the locations.![Location pin on the drawing](/images/kb/103000035168/gLxpNpOsECHf09DGM1XM1o0egzRB1EzsFg.png)
5.  The system will list the locations, allowing you to place the pins on the drawing efficiently without needing to name each one individually.![Location pin on the drawing](/images/kb/103000035168/fFs2o3uycrbs516nYCZWaLBmscH1uPMLLg.png)
