# **Navigation Plan in RDrive**

A **Navigation Plan** in RDrive is designed to enhance user experience and streamline project management within the platform. Below are the key benefits of utilizing a Navigation Plan:

-   **Simplified Navigation:**  
    Provides an organized method for easily locating project drawings and elements.
-   **Adaptability:**  
    Can be easily updated to reflect changing project requirements, ensuring users always have the most current information.
-   **Visual Clarity:**  
    Clearly outlines paths and key components, improving understanding in complex projects.
-   **User-Friendly Interface:**  
    Facilitates interaction for users of all skill levels with drawings and information.

* * *

# **How to Add a Navigation Plan**

Creating a Navigation Plan is a straightforward process that can enhance your workflow. Follow these steps to add a Navigation Plan:

1.  **Access the Main Menu:**  
    Click the **Menu icon (≡)** in the top left corner of your screen to open the main menu.  
    ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/gsFPmzPmm8uiK2DYVb_rB1odlQN2EmjhUQ.png)
    
2.  **Navigate to Drawings:**  
    From the main menu, go to **Settings**, then select **Drawings**.  
    ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/xQxyL_vEGMmvdzzsd8i18aKnZJgPT_0LGw.png)
    
3.  **Add a Navigation Plan:**  
    Press the **+** button to start the process of adding a new Navigation Plan.  
    ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/htljC34KXYxOlqDurlbWnpCo_X-PBEbAPw.png)![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/gkdFr7cN3fyws6llsndjQzUdZeByZ-3ymA.png)
    
4.  **Edit and Confirm:**  
    All drawing set titles will be listed here. Click **OK** if no adjustments are needed, or use the available functions to design the Navigation Plan.  
    ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/XY5wuG9Wpkt1ft4-m7f2AI97YxJKwVC_gw.png)

# **Design the Navigation Plan**

To edit the Navigation Plan, you can use the functions to add locations or add navigation plan layers for storing drawings.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/hFgukYSaZWnvhIZfcRFCxrutghSdFar94w.gif)

-   **Add Location:**  
    Place location pins on the Navigation Plan page instead of on the actual drawing. This is useful for projects that do not require a floor plan or site plan. Project administrators can easily add locations for storing items.
    1.  Click on the **Add Location** button.
        
        ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/UZw9r3Bktv5lZT3pclOms9RRKCAJ3-tpYQ.png)
        
    2.  Input the location's title.  
        ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/9lmhrFnMlvr-EvHB13fxMDpjN3wG6N6hSw.jpeg)
        
    3.  Click on any blank space to confirm, and click **OK** to confirm the edit.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/zzCaqDFOHSn0Q9Ddp3AyR175KYwqfL_VNw.jpeg)
        

-   **Add Navigation Plan Layer:**  
    Add layers for the drawings to control the visibility of various components, enabling users to focus on specific elements without distractions.   
      
    To add a new navigation plan, follow these steps:
    1.  Click on the **Add Navigation Plan** button.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/emx24w3wpH8WMxSei9RYev8g3uM2mTP5kA.jpeg)
        
    2.  Input the navigation plan's title.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/XegXIwaIX7QslczNmjbVfBl6elJYDlw-aA.jpeg)
    3.  Click on any blank space to confirm.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/gE-1PEnIEXrDRGhvtJpeasqtZGpwfbaSnA.jpeg)
    4.  Click on the **Add Drawing** button.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/Qk5_3I60V9CYqMG1tLh1HoVWMpm85bbHSw.jpeg)
    5.  Select the drawing set or drawing(s), then drag and drop them onto the navigation plan title to assign them.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/E1pMuz29AKV7BljbxHa3rgbPZe6_TssB-Q.jpeg)
    6.  Click **OK** to confirm the edit.  
        _Here is an example:_   
        ![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/sDPrahG4OZdQHHbJev76ahFgR4RoAIB5XQ.gif) 

-   **Remove a Navigation Plan or Location:**  
    To remove a selected option from your Navigation Plan:
    1.  Click on the selected option (Text in blue).
    2.  Click the **Remove** button to delete the selected item.![Creating and Managing a Navigation Plan in RDrive](/images/kb/103000313594/aUTaeFQF-uTX4dITSZymuTs89Fxg3RIJLw.jpeg)
