### **Overview**

  
_This guide explains how to manage Drilldown buttons on drawings in RDrive. Drilldowns allow you to create interactive links between drawings, helping users navigate from a high-level overview to more detailed layouts._  
  

-   **Purpose:** To enable users to link drawings together using Drilldown buttons
-   **Who It’s For:** Project admin

  

  

<Note>
Prerequisites: Access to the Plan Viewer and sufficient permissions to manage Drilldown links
</Note>

### **1\. What is a Drilldown Button?**

  

A Drilldown is an interactive icon placed on a drawing that links to another drawing. It allows you to “drill down” from one layout or section to a more detailed or related drawing, such as linking a floor plan to a room layout.

* * *

###   

###   

### **2\. How to Add a Drilldown**

  

1.  Open the drawing in **Plan Viewer**.![Managing Drilldown on Drawings](/images/kb/103000347382/Y0mzjLpzlJ8oxvXseRNDI1lXhUl3P7oavA.jpeg)
    
2.  Click the **Add (+)** button at the bottom right corner.![Managing Drilldown on Drawings](/images/kb/103000347382/YIyUaAFhyN2rFsVgvaUBywQiEXDGL3ZNUg.jpeg)
    
3.  Select **Drilldown** (this option only appears if you have permission).
    
4.  Drag the drilldown to change its position, **OK** to confirm.![Managing Drilldown on Drawings](/images/kb/103000347382/SR2r_JYNVe0sRXBlqoavCNRs_j6o-Bxl7g.jpeg)  
      
    
5.  Select the **Linked Drawing** you want to associate.
    
6.  Click **OK** to confirm.  
    ![Managing Drilldown on Drawings](/images/kb/103000347382/lItiW1WMvLbhYfnvdPEcp-iQedOXou-Q0A.jpeg)
    

* * *

###   

###   

### **3\. CHOOSE to Add Drilldowns in One Go**

  

If you want to add multiple Drilldowns quickly:

1.  After opening the drawing, click the **Add (+)** button and select **Drilldown**.
    
2.  In the dialog, click **CHOOSE**.![Managing Drilldown on Drawings](/images/kb/103000347382/X9w_kS-_YF9R5tpMGgeGDepc7pmTszs6eQ.jpeg)
    
3.  A list of all drawings in the project will be displayed.  
    ![Managing Drilldown on Drawings](/images/kb/103000347382/mFP89VgygZ_wFjgYLArJ9cHZyOh92Z2Rbg.jpeg)  
    
4.  Select a drawing and place the Drilldown on the current drawing.
    
5.  The next drawing in the list will appear — continue placing Drilldowns as needed.
    
6.  Click **Cancel** to finish the process.  
      
    

![Managing Drilldown on Drawings](/images/kb/103000347382/aqtylyqcyPzCSB03VBqlCexpvorC-VxJkw.gif)

  

This feature allows you to add multiple Drilldowns in a single flow, improving efficiency when linking multiple drawings.

### **4\. How to Edit a Drilldown**

  

1.  Long press on the existing Drilldown button.![Managing Drilldown on Drawings](/images/kb/103000347382/aYcBo8zu2OEYrf5Cd8MkRVqw_tuXuNy4qQ.jpeg)
    
2.  A dialog box will appear in the top left corner.
    
3.  Click the **three-dot icon (︙)** in the dialog.![Managing Drilldown on Drawings](/images/kb/103000347382/01nhYlLssM8DbmTnMoIk-VCKqtIcgl47MA.jpeg)
    
4.  A menu will appear with options:
    
    -   **Edit**: Change the linked drawing.![Managing Drilldown on Drawings](/images/kb/103000347382/kCJbycUa0AqpRPe6SLZxy_Wgg3beDqQ63A.jpeg)![Managing Drilldown on Drawings](/images/kb/103000347382/0CS3sEQ3_C2vPTu2tU_oKBqG7c_LdjJecQ.jpeg)  
          
        
    -   **Move**: Reposition the button on the drawing.![Managing Drilldown on Drawings](/images/kb/103000347382/01eOxJm3h3NiPFieNuZQ43mW5jPNAKJ30A.jpeg)![Managing Drilldown on Drawings](/images/kb/103000347382/nnS-SDsrn0kRCQxO4aV12JT8FnbpjzdGlA.jpeg)  
          
        
    -   **Delete**: Remove the Drilldown from the drawing.![Managing Drilldown on Drawings](/images/kb/103000347382/p4h3pcBAtWqbTaH6ze86fRcmWFwSmXgDrg.jpeg)![Managing Drilldown on Drawings](/images/kb/103000347382/_oSZLIlGOJRKP73CMFJvjYfwB324vF_BlQ.jpeg)

### **5\. Tips & Reminders**

  

-   Drilldown options only appear for users with edit permissions.
    
-   Be mindful of the placement to avoid overlapping with important drawing content.
    
-   Use meaningful linkages to improve navigation efficiency for your team.

###   

###   

### **6\. FAQs & Troubleshooting**

  

### **Q: I don’t see the Drilldown option in the Add (+) menu. Why?**

A: You likely don’t have permission to add Drilldowns. Please contact your project or company admin.

  

* * *

## **Q: Can I link a drawing to multiple Drilldowns?**

A: Yes. One drawing can be linked from multiple other drawings via separate Drilldowns.

  

* * *

### **Q: Can I adjust the icon or appearance of the Drilldown button?**

A: No, the Drilldown button style is fixed and cannot be customized. Its size and icon are standardized to ensure consistent user experience across all drawings.
