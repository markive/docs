Log in to **Company Area**. 

<Info>
Only the company admin can access this page.
</Info>

Click **Settings** and select **Categories**.

![Edit the category and subcategory](/images/kb/103000035054/GZYSS1WoYQL3UmF8A_RnZaUQUFoeuOUEhw.jpeg)

![Edit the category and subcategory](/images/kb/103000035054/S22lmY6tK0ebc5XPuW1U4Wu7fWzf31-WlA.jpeg)

You can able to click on the title to **rename** it,

![Edit the category and subcategory](/images/kb/103000035054/pgxERp_bYI1gl5lLsGzvK_eGxNqtFySqzQ.jpeg)

or click the ⋮ and select **DELETE** to delete it.

![Edit the category and subcategory](/images/kb/103000035054/vEgPudquMIqbCHyYjtudGCnzCY4ZbIE5kg.jpeg)

![Edit the category and subcategory](/images/kb/103000035054/RsRbM16LZ7h2pByOZFwL0T6cilugavU7aw.jpeg)

You will not be able to delete the category if it is currently used.

![Edit the category and subcategory](/images/kb/103000035054/g-Os4__GWF0Qy1ToJ7eNDYhGU4toSELc9w.jpeg)

For the subcategory, you can drag the ＝ to **reorder** it,

![Edit the category and subcategory](/images/kb/103000035054/xCMF9kGgDI3cSKiyiJVJrGpSqopBwt1mXQ.jpeg)

click the ⋮ and select **EDIT** to edit the subcategory code and title,

![Edit the category and subcategory](/images/kb/103000035054/xuLIAil6mzxAjOQmINQqDZOkzbZ870ZaWA.jpeg)

![Edit the category and subcategory](/images/kb/103000035054/EKNbnp1s-GD5AwbsXDxA85ha-DAMesoMBw.jpeg)

**OK** to confirm,

![Edit the category and subcategory](/images/kb/103000035054/6seRHsh5-yXtyUb2eUARv5LaqkLv9QTuig.jpeg)

or select **DELETE** to delete it.

![Edit the category and subcategory](/images/kb/103000035054/RScT_qQ2I9qvwRKhbcv6Udm3O8v4OJvu8Q.jpeg)

You will not be able to delete the subcategory if it is currently used.

![Edit the category and subcategory](/images/kb/103000035054/Rbpma8AusSxo2CbADbL_r_k53PMQfgE5UQ.jpeg)

Check **_[here](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035083-how-to-recategorize-)_** to know how to recategorize those templates.
