You may

-   [Access to issue wizard to edit the content](#h_3e5e14e636)

## Access to issue wizard

You may edit the

-   [Data layer,](#h_0f567fb640)
    
-   [Display layer,](#h_c1f91e1d56)
    
-   [Report template,](#h_c1f91e1d56)
    
-   [Issue status,](#h_c1f91e1d56)
    
-   [QRcode import template](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/how-to-add-qr-code-import-template-to-an-issue-record)
    

on the issue wizard page.

Click the **≡** button to expand the menu and select **Edit.**

![Edit an issue/record template](/images/kb/103000035044/NbIN_pxvEcFdVWkVs4zK05Vlyb8VBKQ83w.jpeg)

![Edit an issue/record template](/images/kb/103000035044/UGDkwuhAaDhE_oWoRO8b8BtR1_kuItsbew.jpeg)

-   Data layer & Issue statuses

To edit the data layer and issue statuses, you will have to create a new version.

Click **EDIT** to create a new version for edit.

_⚠️ Attention: Unless only editing tags, you have to create a new version and publish it after being changed._

_? If you made a mistake on the new version accidentally, you are able to [Rollback](https://docs.rdrive.io/setup/company/categories/categories-template-setup-knowledge-base/what-happens-when-i-use-rollback) to the previous version anytime._

![Edit an issue/record template](/images/kb/103000035044/qjiFPg-e3LUvhNKksrAYUX3g9JbXqofKSw.jpeg)

then you may start to edit the fields on the [data layer page](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/create-an-issue-record-template#h_04e4fdca96).

![Edit an issue/record template](/images/kb/103000035044/aGO0t2QHVzdA7VGVxA1dnbIycmYXKUZbAA.jpeg)

or click the **Issue statuses** option (or ⌘/Ctrl 5) from the **⋮** button to edit the [issue statuses.](https://intercom.help/rdrive/en/articles/5691052-create-an-issue-record-template#h_a60a7c497d)

![Edit an issue/record template](/images/kb/103000035044/dguk8CYY7BkaQQeUvJbQXr7PmlgeHHaKmg.jpeg)

⭐️ [Remember **SAVE** and **PUBLISH** after changed!!](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/create-an-issue-record-template#h_5f03d6a78d)

-   Display layer, Report layer

To edit the display and report layer, you don't have to create a new version.

Select the **latest version**, click **EDIT** to access the wizard to edit.

![Edit an issue/record template](/images/kb/103000035044/cawv1RzzGC1y6Q9j8M0yZhyhMl0HJABFsQ.jpeg)

![Edit an issue/record template](/images/kb/103000035044/ihvI_zqFGU5llJ0KOzGCb51ca1Y_e_2FrA.jpeg)

![Edit an issue/record template](/images/kb/103000035044/nhX7FuShVP2bWE4osfn__bZ9xPrRLbyOjA.jpeg)

then you may start to edit the [display layer,](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/create-an-issue-record-template#h_650ddc4a6b)

![Edit an issue/record template](/images/kb/103000035044/xM119dhvVsxiWgqgQXNo2XrfAy8qpLkcvA.jpeg)

or edit the [report template.](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/design-an-issue-record-report-template)

![Edit an issue/record template](/images/kb/103000035044/eWEfGiIhydXKAlrNYI3Zzoby6mlFN5khVg.jpeg)

## Rename

You can [single edit](#h_c3ea9e2349) the template title & template tag(s) on the BROWSE viewer and [batch edit the tag(s)](#h_64edba9865) on the SELECT viewer.

-   Single

Click the **≡** button to expand the menu and select **Rename**.

![Edit an issue/record template](/images/kb/103000035044/682UeGGtohlcaN-zRODJq8MgHLXFIa1lNw.jpeg)

![Edit an issue/record template](/images/kb/103000035044/C6Y_bCrd6NG7Pu8vC2RNBdFdMgCgTyhsXA.jpeg)

In this dialogue, you may edit the title & tag(s) of this template.  
Press **OK** to confirm the change.

![Edit an issue/record template](/images/kb/103000035044/rCMlVaU2GfXx7wAS4lFqZLnWFsSwp_dctA.jpeg)

-   Batch edit tag(s)

Switch the mode from **BROWSE** to **SELECT**.

![Edit an issue/record template](/images/kb/103000035044/YtxbKQwapmpQEwhGlikgo0dmVgTDpeQjxA.jpeg)

![Edit an issue/record template](/images/kb/103000035044/dnd6nOlloMvWa-i5Kw1cUnmflW8qSfyDzw.jpeg)

On the SELECT, you can click on the template or press the **select all** / **deselect all** button to select item(s).  
The selected will be highlighted in grey.

![Edit an issue/record template](/images/kb/103000035044/q4hwu5Qjn70pzOZxqDPrah-DQCiRIcY2Zg.png)

![Edit an issue/record template](/images/kb/103000035044/z-ngKGj_Uc6H2NA3wcuSM0z5HqS9AHqRow.jpeg)

Press the **rename** icon to batch edit tag(s).

![Edit an issue/record template](/images/kb/103000035044/VSZT5Va7QMfXznLDF5goU54K1m0kjE3oDQ.jpeg)

Enter the tag(s) you need to add or need to remove.  
**OK** to confirm.

![Edit an issue/record template](/images/kb/103000035044/Xymw0vtib93r3zxh42YdSFXwoo2ioumRXQ.jpeg)

## Rules

Click the **≡** button to expand the menu and select **Rules** to open the dialogue.

_The assignment rule set from the company area will automatically appear on all project issue profiles._

![Edit an issue/record template](/images/kb/103000035044/IZfyyTzaYyjOOeVnhItsWR5pOaOnyWCrZA.jpeg)

![Edit an issue/record template](/images/kb/103000035044/SgOTmsXXnm-x6qOd6Ppqd1894RWHMvly1Q.jpeg)

Press the **ADD** button to add a new rule to configure this issue or click on the existing **rule** to edit.

![Edit an issue/record template](/images/kb/103000035044/1j9_8_UJRw6yFp_kh6wyH6xujkAIgrtw1w.jpeg)

![Edit an issue/record template](/images/kb/103000035044/QGrpyGRs5EkdE7iX1zv-C_lcv44N4Eh9Sw.jpeg)

Select Issue status, assign attributes and Issue data if needed.  
**OK** to confirm.

![Edit an issue/record template](/images/kb/103000035044/ocK1V1R-ILAYldiAdCQLj6B88D7d5XqTWg.jpeg)

For more detail of the assignment rule, please reference [HERE](https://docs.rdrive.io/setup/project/category-issue-profiles/assignment-rule-issue-profile).
