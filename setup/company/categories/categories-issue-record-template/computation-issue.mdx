# What is Computation?

Computation - is a field module to assist you in designing your template with "computed fields". It can bring the ability to define fields on an object whose value is computed from the values of other fields.

Most of the formulas in Excel apply to Computation in RDrive.

E.g.: SUM, VLOOKUP, AVERAGE, LEN, IF, etc.

* * *

## How to set up the computation to an issue template?

First, you have to [edit](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/edit-an-issue-record-template) /[create fields](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/create-an-issue-record-template) and [assign field types](https://docs.rdrive.io/setup/company/categories/categories-template-setup-knowledge-base/what-can-field-properties-do) to design the template layout in the issue wizard.

## Assign value

INPUT & OUTPUT

An input field can be any field type.  
An output field can be any field type except image, signature, team list, user list and dropdown list.

Click **SELECT** to select fields from the form to assign the spreadsheet cells for the input value.

![Computation - Issue](/images/kb/103000035013/W5bxJzwJWhaacHzKplppu789k4fMfrs2gw.jpeg)

Click on the field to choose, the selected field will highlight in blue.

Press the ✔️ on the bottom right to confirm;

or clicking outside of the dialogue to cancel.
