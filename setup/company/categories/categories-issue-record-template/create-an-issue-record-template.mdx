This template helps you to capture issues/records via mobile app and generate issue reports in a click.

Issue/record normally will work with the preset list, is used to speed up the process of capturing defects/record and facilitate subsequent data analysis. A hierarchical list can help to look for a relevant description efficiently through layers of issue/record type.

Log in to **Company Area**. _(Only the company admin can access this page.)_

Click **Settings** to access the **Categories** page, select **Category** and **Subcategory** to add the template.  
_[Click here to know how to add a category and subcategory.](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035055-how-to-add-a-category-and-subcategory-)_

## Issue Statuses

Click the **Issue statuses** option (or ⌘/Ctrl 5) from the **⋮** button to bring up the status dialogue for the company admin to manage the statuses for this template.

![Create an issue/record template](/images/kb/103000035067/j9sDUwJpzXUJFxHzLNuEWT8FSf7xyq2a3A.jpeg)

![Create an issue/record template](/images/kb/103000035067/LMC8HumpnSHtobx3cpXpn9eXhxtj32MZ7w.jpeg)

Will have 3 statuses by default, 1 Draft, 1 Open, and 1 Closed.  
You may click the **ADD** button on the bottom right corner to add a new status.

![Create an issue/record template](/images/kb/103000035067/sBNJSmrNh75WXQR-8JvmROvHxP16xQxmnA.jpeg)

Select status stage, choose a color to present this status, enter the title and [status tag(s)](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035133-how-are-tags-used-), and the [conditional editing setting](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035133-how-are-tags-used-).

![Create an issue/record template](/images/kb/103000035067/ba0qHIfMZoI_BGdptAUPjLgb4rIq-JvKfw.jpeg)

**OK** to confirm.

_\*Tips: Enabled the conditional editing without any field tag is mean it is not editable on this status._

and, you may edit an existing status as you fit.
