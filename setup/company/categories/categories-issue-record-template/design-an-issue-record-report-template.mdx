Please access the **[Report layer](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035067-create-an-issue-record-template#h_bff4f3328d)** by Company level ➡ Settings ➡ Categories ➡ Subcategories ➡ issue template ➡ issue wizard ➡ report layer to start.

We are able to edit the [report content](#h_3304f9498e), [copy and paste](#h_fd49d2115e), [delete](#h_3f86dfd0d8) and [add](#h_fde236c58c) report there.

![Design an Issue/record report template](/images/kb/103000035043/_3TY2nb3zHv_40H6D_hJKleZ1yCK4KnPPQ.jpeg)

## Report content.

Let's start by building a report from the beginning.

Default and History reports will be created without any content once the template is created as default.

Press the ✚ button from the bottom right to add the data box.

![Design an Issue/record report template](/images/kb/103000035043/vEa6bM_y0Jx_J1CxOLq9wGHc4IM-S41oQg.jpeg)

In the pop-up dialogue, You may select a **[Field](#h_c6025ea72e)** from the data layer, **[Text](#h_6fe2b445e7)** for free text, and **[Attribute](#h_7d870c8ae7)** of the issue/record by the below button.

![Design an Issue/record report template](/images/kb/103000035043/J0W9aJKKiQ73QyvFuxHfvUA37oxbO9_N2w.jpeg)

![Design an Issue/record report template](/images/kb/103000035043/fVbb7JroCYycyfFLcEgS-1mqr1M9MEyD3g.jpeg)
