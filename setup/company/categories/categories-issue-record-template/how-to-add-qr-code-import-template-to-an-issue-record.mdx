The users can [auto-fill multiple fields by scanning the QR code via the APP](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035069-scanning-qr-code-to-auto-fill-an-issue-record) when the QR code import template is set. 

<Info>
(not applicable to image, checkbox, pass/fail/NA, signature field types)
</Info>

* * *

Let me show you how to add the import template.

First, log in to **Company Area**. 

<Info>
Only the company admin can access this page.
</Info>

Unfold the menu, click **Settings,** and select **Categories.**

![How to add QR code import template to an issue/record?](/images/kb/103000035065/1s53Olr_7hvbAzD6HK5LxHktKLM_rxYosQ.jpeg)

![How to add QR code import template to an issue/record?](/images/kb/103000035065/mjbQWVASZMw_zEGoGcSpHkMQ_9EIQlP9Iw.jpeg)

Click into the form wizard which you wanna add the QR code import template, by Category ➡ Subcategory ➡ Issue ➡ Issue wizard.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/uvo8dLHTqzcXvVPOSPFvMnmqwc1WyL26LA.jpeg)

Choose an issue template, click the **≡** button to expand the menu.

Select **Edit.**

![How to add QR code import template to an issue/record?](/images/kb/103000035065/PJiQOvgluCbNgWGywspt6wb8QIzhHplzeQ.jpeg)

![How to add QR code import template to an issue/record?](/images/kb/103000035065/3J6Qjm_KYNmQmTn6rDraaM4g1P-oZIvlkQ.jpeg)

Select the latest version, click **EDIT.**

<Note>
⚠️ Attention: Unless only editing tags or QRcode import template, you have to create new version to edit a form template and publish it as a new version after being changed.
</Note>

![How to add QR code import template to an issue/record?](/images/kb/103000035065/xqomf8rIPxfaD84JEfVrl3Cdsl1Quo6lDQ.jpeg)

Click the ⋮ and select **QR code import.**

![How to add QR code import template to an issue/record?](/images/kb/103000035065/5IxtJ1Lmp6W4-qmdjehd7oU2OrCmlwHQEA.jpeg)

![How to add QR code import template to an issue/record?](/images/kb/103000035065/izIZ_6H4WY1YakvOtdnxLpP-9xX2y1rOYA.jpeg)

Press **ADD**

![How to add QR code import template to an issue/record?](/images/kb/103000035065/TAQo1a5xgWO0lQtq4B9g3pw8k0iKVFsm6A.jpeg)

To add a QR code import template, you may 

-   [Choose one of three data types to design the mapping.](#choose-one-of-three-data-types-to-design-the-mapping.)
-   [Upload a QR code based on the content and map with the data type.](#upload-a-qr-code-based-on-the-content-and-map-with-the-data-type.)

* * *

## **Choose one of three data types to design the mapping.**

There would have a pattern below on each data type for reference.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/GMMe6jsrgENzdS4pu8hw5Zlu3NWekjZKGw.png)

Below will use **ARRAY** to add a template as an example.

Enter **Title**, choose the **data type**.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/vqg3lNUhxXV7tmq6XXOm2SDD3Oy4BjJnJQ.jpeg)

To create an ARRAY template, a separator is a key for mapping.  
Input the separator and add number of fields for mapping as you need.

Click on the **Issue field** to start mapping.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/wL9GDPA78boB538AYkfOVfUw7haG6y8auA.jpeg)

Select the related field one by one to map.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/HjjV68aL7SDpLaazu0MqemorROY2IiOPLA.jpeg)

**OK** to confirm.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/ebaqBnjhX1CxeScnFKiAEvELvFMgsjcA6Q.jpeg)

Template created.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/2m-bQnDuwjkJ0_PyKAFEXMXuACUm-airzw.jpeg)

* * *

## **Upload a QR code based on the content and map with the data type.**

If you have a QR code on your hand, you could upload it to detect the mapping by the content.

Select **UPLOAD**

![How to add QR code import template to an issue/record?](/images/kb/103000035065/ZnlbV6koqfeAh3W32ltOQfKvh_Go7nZMJw.jpeg)

Click to select the QR code from your file to upload for detection.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/JzMSqZ3Wz3L_7VuQO7Tuew5JklNEYh3GsQ.jpeg)

The content of the QR code will display as below, you may check and edit from here if necessary.  
**OK** to detect.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/npB820AqSePV1jNzCge4qDY3pzXRXiybRA.jpeg)

Click on the **Form field** to start mapping.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/NQtRN66BSwQp3GKM9jguYLWne00q7HOUbw.jpeg)

Select the related field one by one to map.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/yVeUDDTf55UdUIlcR0nKb4qWS-3xrAJqeg.jpeg)

**OK** to confirm.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/kAD77taWPycdsZncXOKisOZA2aJ-g_fVOg.jpeg)

DONE.

![How to add QR code import template to an issue/record?](/images/kb/103000035065/1-sio7UvLjwJNjP2ek7Xq7dQnlqocINVFw.jpeg)
