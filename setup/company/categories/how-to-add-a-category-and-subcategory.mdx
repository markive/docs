**Category** is a classification tool for you to manage all the templates.

It is one of the customization features on this system for the company admin to design how would the menu look like and how would it display.

You can group templates by type, by area, by participants or by use case etc, all as you needed.

Templates have to belong to one subcategory.

* * *

  
First, log in to **Company Area**.

<Info>
Only the company admin can access this page.
</Info>

Click **Settings** and select **Categories**.

From here, you can add a category and subcategory.

![How to add a category and subcategory?](/images/kb/103000035055/zvgKKI88S2dZJZth4jL-lPeB7NjlTetObw.jpeg)

![How to add a category and subcategory?](/images/kb/103000035055/L3tEjNemXVMd_CYT9cUj6fZKc1F_iyDXmQ.jpeg)

You can create a new category by clicking the **⊕** button.

![How to add a category and subcategory?](/images/kb/103000035055/KiQH6VszrpT_AN2FcIj8U9wq0WPXjsvMwA.jpeg)

Choose an icon, enter the category title, click **OK**.

**UPLOAD** if you have a downloaded file.

![How to add a category and subcategory?](/images/kb/103000035055/TTQA4EnqYNAlBVZfXPrEK48AsTEQPlQDxA.jpeg)

Category added!

Next, you can add a subcategory to this category. Click the **✚** button at the bottom right corner.

![How to add a category and subcategory?](/images/kb/103000035055/KePRMXIEm-ApFLCjGmBKMR4Yjji4Iu9t6g.jpeg)

Enter the subcategory code and title, select the template type _(Issue/record or process)_.  
Click **OK** to save.

![How to add a category and subcategory?](/images/kb/103000035055/pqMNXAznEzXE_kMI2622m7U22HgxnFJQZg.jpeg)

Subcategory added.

  
From now, you may access the subcategory to add template(s) or recategorize the template(s) to there.

![How to add a category and subcategory?](/images/kb/103000035055/k6xlIQh1A9CLPYtiYyePietlWqmameSOmQ.jpeg)

![How to add a category and subcategory?](/images/kb/103000035055/fEls674x1K05gq5iKjjMGpd9_5gGnFaQbw.jpeg)

## 

<Note>
Tips:
If the Category and Subcategory have the same title, they will be displayed as 1 tier on the project menu. 
(only available to the category with one subcategory)
</Note>

![How to add a category and subcategory?](/images/kb/103000035055/2YAyLHG6NUJsHixmBqFBbBODsdKi-Pheig.jpeg)

![How to add a category and subcategory?](/images/kb/103000035055/5JbdYdlWUbVamaenV_5Rm3mq9LJd9hchCw.jpeg)

If the **Category** and **Subcategory** have a different title or the **Category** have multiple **Subcategories**, they will be displayed as drill-down items on the project menu.
