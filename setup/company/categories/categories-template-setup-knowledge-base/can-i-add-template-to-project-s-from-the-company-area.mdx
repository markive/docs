Sometimes, you created a new template and wish to add it to the project(s). This article is to show you how.

[Process template](#h_eee204dc2b)

[Issue template](#h_40785f045b)

* * *

## Process template

Find the Process template by Company level > Menu > Setting > Categories > Subcategory.  
Click the **⋮** button next to the create new version/Publish button and select **Add to projects**.

_⚠️ Attention: This action no need to create new version._

![Can I add template to project(s) from the company area?](/images/kb/103000035082/st3ON_f9dcddN1dlUQDvPGrQyZjNulfPzQ.jpeg)

![Can I add template to project(s) from the company area?](/images/kb/103000035082/l6tpGFAY4-O07nfkLLAHucomzjsUcN4P5A.jpeg)

On the first page of the dialogue, it will display the project(s) which currently using this template as a profile.

**ADD** to add others.

![Can I add template to project(s) from the company area?](/images/kb/103000035082/EmAEJBjdNOwGhKpRgxVNytzHDh6dk53J3Q.jpeg)

You may create a blank new profile or clone from an existing one.

Enter the **Code** and **Title** to create a new one

![Can I add template to project(s) from the company area?](/images/kb/103000035082/sKTBmK7wYdYMiyb7xqGzoQb5wpAsFob0ug.jpeg)

or select the existing process profile from the project, edit the code, title, digits setting to clone.

**NEXT** to select project(s) to add.

![Can I add template to project(s) from the company area?](/images/kb/103000035082/DU58qiG7xhOXivCDXQK78J_ER0xftwCBYA.jpeg)

**OK** to complete.

![Can I add template to project(s) from the company area?](/images/kb/103000035082/uqDSJl5khf3BcAGiQKCyqATDztTCRrYQfA.jpeg)

Done.

## Issue template

Find the Issue template by Company level > Menu > Setting > Categories > Subcategory.

Choose an issue/record template, click the **≡** button to expand the menu.  
Select **Add to projects**.

_⚠️ Attention: This action no need to create new version._
