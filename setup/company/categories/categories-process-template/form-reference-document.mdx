To help your users understand specific requirements or expections from the form or process you can provide reference material

  

These reference guides can be accessed by any user with access to the form.

  

The form reference document will automatically attach to each created form on projects.

* * *

  

Please access the template page by 

Company level > Menu > Setting > Categories > Subcategory > Process template > create a new version to access the **draft** **mode** to add/edit the form reference document.

  

<Note>
⚠️ Attention: Unless only edit tags, you have to create new version to edit a form template and publish it as a new version after being changed.
</Note>

  

  

  

Choose a form, click the **⋮** button at the top right corner of the form list select **Documents.**

![Form Reference document](/images/kb/103000035045/g47yOEBF9oQAsQ0PHHQVrCU6oG26HRPjaA.jpeg)

Click to **EDIT**

![Form Reference document](/images/kb/103000035045/skv3yumoxL936Rw9SlY4CGIQz_fIuIb43w.jpeg)

Upload the document(s) from your desktop.

![Form Reference document](/images/kb/103000035045/mb0xlhnF8Ch7YTIRAV-nY9OTxyxCjhqF0w.jpeg)

1 document was added.

to remove, **OK** to confirm.

![Form Reference document](/images/kb/103000035045/FJhTGUMQy_DBaSU8-_zlkBO3wsFNQFr6cQ.jpeg)

It is added!  
You can see 1 document is uploaded.

  

![Form Reference document](/images/kb/103000035045/4jCL_m9SI7GAEJu24T9Vqh8-3qe_3wWRCQ.jpeg)

Remember to [publish](https://docs.rdrive.io/setup/company/categories/categories-template-setup-knowledge-base/why-do-we-need-to-publish-the-template-after-changes) as a new version when finished.
