title: "How to add QR code import template to a form?"
description: "The users can auto-fill multiple fields by scanning the QR code via the APP when the QR code import template is set."
---

The users can [auto-fill multiple fields by scanning the QR code via the APP](https://docs.rdrive.io/mobile/issues/issue-viewer-fill-data-change-status/scanning-qr-code-to-fill-an-issue-record) when the QR code import template is set. 

<Info>
(not applicable to image, checkbox, pass/fail/NA, signature field types)
</Info>

Let me show you how to add the import template.

* * *

First, log in to **Company Area**. Only the company admin can access this page.

Unfold the menu, click **Settings** and select **Categories.**

![How to add QR code import template to a form?](/images/kb/103000035066/uU_ZeGiHy990zjNgkHv8tPBkDhHu33tqCA.jpeg)

![How to add QR code import template to a form?](/images/kb/103000035066/Ek6QDi1EOKf3cKZioCn7kw-RzaImWbjarA.jpeg)

Click into the form wizard which you wanna add the QR code import template, by Category ➡ Subcategory ➡ Process ➡ Form ➡ Form wizard.

![How to add QR code import template to a form?](/images/kb/103000035066/UXI9j4ogw30Xgmn0wiX-ee9i48EGUiOOfA.jpeg)

![How to add QR code import template to a form?](/images/kb/103000035066/ZK743c9lILmrobPNZ4Wy6GsJXNi1XMmFEA.jpeg)

Click the ⋮ and select **QR code import.**

![How to add QR code import template to a form?](/images/kb/103000035066/4MFXApNWSMpQP-GcOMcWkEInxlq6Rjy96g.jpeg)

![How to add QR code import template to a form?](/images/kb/103000035066/0E2lx-bWEC0j-Dlk_jzaWYBZwJSeG19loA.jpeg)

Press **ADD**

![How to add QR code import template to a form?](/images/kb/103000035066/BxQ3SrIZgkUP47_MgW8IHMxiBtnVcAEcdA.jpeg)

To add a QR code import template, you may 

-   [Choose one of three data types to design the mapping.](#choose-one-of-three-data-types-to-design-the-mapping.)
-   [Upload a QR code based on the content and map with the data type.](#upload-a-qr-code-based-on-the-content-and-map-with-the-data-type.)

* * *

## **Choose one of three data types to design the mapping.**

There would have a pattern below on each data type for reference.

![How to add QR code import template to a form?](/images/kb/103000035066/aAhbL3VPDa1jkjvnpBVQC7skKdYt3ejR8w.png)

Below will use **ARRAY** to add a template as an example.

Enter **Title**, choose the **data type**.

![How to add QR code import template to a form?](/images/kb/103000035066/8KsqO3a_1VCVpBvjwX1F_BTbkqQ1iyYavA.jpeg)

To create an ARRAY template, a separator is a key for mapping.  
Input the separator and add number of fields for mapping as you need.

Click on the **Form field** to start mapping.

![How to add QR code import template to a form?](/images/kb/103000035066/NguB4_mfzeVlSpu4VQik_bnyKrYFxpb_1w.jpeg)

Select the related field one by one to map.

![How to add QR code import template to a form?](/images/kb/103000035066/FHXgT-o3icF3DoumR5j79TeFr1JFfxlULg.jpeg)

**OK** to confirm.

![How to add QR code import template to a form?](/images/kb/103000035066/ew5s9QlZvA85s80p7TasAt-lsPViaU8yjw.jpeg)

Template created.

![How to add QR code import template to a form?](/images/kb/103000035066/15bPR1YDNwtrQ9IwRwaG7ZvH4vNXa_D1TQ.jpeg)

* * *

## **Upload a QR code based on the content and map with the data type.**

If you have a QR code on your hand, you could upload it to detect the mapping by the content.

Select **UPLOAD**

![How to add QR code import template to a form?](/images/kb/103000035066/4Wk9gSxnsSqLvCzLZrJk66cgkSdtVAaaoQ.jpeg)

Click to select the QR code from your file to upload for detection.

![How to add QR code import template to a form?](/images/kb/103000035066/is2gQIIH_c2OclYAkw_MWprLSEZpBC7MxQ.jpeg)

The content of the QR code will display as below, you may check and edit from here if necessary.  
**OK** to detect.

![How to add QR code import template to a form?](/images/kb/103000035066/66wbOuZHerkZ8n5kjTMqHxDVVy-ALYo_aw.jpeg)

Click on the **Form field** to start mapping.

![How to add QR code import template to a form?](/images/kb/103000035066/VHw3Ef5py02npDF7z1l3V-Tnp2_iiBm0OQ.jpeg)

Select the related field one by one to map.

![How to add QR code import template to a form?](/images/kb/103000035066/FHXgT-o3icF3DoumR5j79TeFr1JFfxlULg.jpeg)

**OK** to confirm.

![How to add QR code import template to a form?](/images/kb/103000035066/3sls391b2HURuOHdWoGaz1Hk1oY3plLfaw.jpeg)

DONE.

![How to add QR code import template to a form?](/images/kb/103000035066/Gb6C4_i3cndOyVyBb0WeiicTcTfRRlmxrQ.jpeg)
