It is not uncommon that various business processes, e.g. daily site walk, quality / safety checklist, request for inspections, etc. remain in paper-based system.

It is possible to digitalize them in RDrive and there are many ways to go about it. The best solution often comes from a **clear understanding of the business process** where the form is involved. It translates to the **business requirements** that guide you to configure the template set up.

## Overview

It is important to first understand:

1.  [Process Template](#h_b488f568b3)
    
2.  [Form Template _(Default form and Optional form)_](#h_2dc3a6beb7)
    

_What's the difference?_  
A Process **Template** is an umbrella, that consists of **a Form Template** or **a combination of Form Templates**.

First, log in to **Company Area**. _(Only the company admin can access this page.)_

Click **Settings** to access **Categories** page, select **Category** and **Subcategory** to add the template.  
_[click here to know how to add a category and subcategory.](https://docs.rdrive.io/setup/company/categories/how-to-add-a-category-and-subcategory)_

## To add a process template.

You can create a new template by clicking the **⊕** button.

![Create a process template with form](/images/kb/103000035068/K87ShrBIHfodbbxqyRZKJjMomQ5MT7oLwA.jpeg)

Enter the process code and title, click **OK**.

**UPLOAD** if you have a downloaded file.

![Create a process template with form](/images/kb/103000035068/d7V3dicCQo5qQVFAtoMRJ6utXd7f6NjAXA.jpeg)

## Process created!! Now we can start to add a new form template;)

Click the **✚** button at the bottom right corner.

![Create a process template with form](/images/kb/103000035068/8m7S8bT-TvQcnR_Hh620HHxMEPpQ7YT3ZQ.jpeg)

Enter the information of the form, such as Form code, Title, Tags, Description, Language, Default form or Optional.  
Click **OK** to save.

_What is the Optional form?_  
An Optional form is not included in the process when the process is added, the user can add it by the **Add form** function when needed.  
Will be using it for the additional page of the form normally, such as the photo page, check items etc.

![Create a process template with form](/images/kb/103000035068/4ZAlT_lX78vCptAz5Eyq2RgpbY6YPsYc5Q.jpeg)

Form template created. Now, please upload the form image(s).  
You can upload a PDF with multiple pages or upload images one by one.

![Create a process template with form](/images/kb/103000035068/s1rQ36MD2WIED5rpTmC43koZbx_s9cNnrA.jpeg)

![Create a process template with form](/images/kb/103000035068/PcKXcNDS4V9VkB_nwfm-LFBEDMObvicHMQ.jpeg)

If you need to add more form(s), kindly click the **✚** button at the bottom right corner to continue adding, so on.

![Create a process template with form](/images/kb/103000035068/4kBoMAltTTD7719Knp4Mvs_pyjgMKFmm-g.jpeg)

![Create a process template with form](/images/kb/103000035068/xt4hGSvAU6ornJGBqIMNeImCawz5tnOjuw.jpeg)

Then, click the magic pen to access the form wizard to set up a digital form.  
To set up the form template below is a compact guide. For more details, please visit **[THIS PAGE.](https://docs.rdrive.io/setup/company/categories/categories-process-template/what-can-i-do-at-the-form-wizard)**

_Can the Form template be used in more than one Inspections?_

_NO._

![Create a process template with form](/images/kb/103000035068/HV2ty78UNJWCwPR9kb5f7JSa6XS98RLvqQ.jpeg)

Save and return to the process template page to carry on after form set up.

![Create a process template with form](/images/kb/103000035068/UrYtqZfTd7TmsPuLmgykcdeH3VclBEwtyg.jpeg)

Enter a message to remind you what this release is about.  
**OK** to confirm.

![Create a process template with form](/images/kb/103000035068/4k0-LizMgWuNu2QyMebsaVKfYJmzVdB4QQ.jpeg)
