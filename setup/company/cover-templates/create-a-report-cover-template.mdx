A cover page is an optional item for the users to select when generating the reports. Could use for the [daily, weekly and monthly report](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035114-manage-the-report-policy), [download process](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035211-can-i-export-the-entire-process-as-pdf-#h_35d2698739), and [download issue/record](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035219-how-do-i-generate-an-issue-defect-record-report-#Via-Issue-finder) from the finder.

First, log in to **Company Area**. _Only the company admin can access this page._

Click **Settings** and select **Cover templates**.

![Create a report cover template](/images/kb/103000035042/CXM2vzo-m0leoS7pQtAVDHYJQr0OThzOnA.jpeg)

![Create a report cover template](/images/kb/103000035042/iZCm3G1Gyg0ygXHPFTTdFXfHKf2U-xjJTg.jpeg)

You can create a new template by clicking the **⊕** button.

![Create a report cover template](/images/kb/103000035042/6eqf_RqzCBVtOs73KLipQGCRy_AUCzcvqQ.jpeg)

Enter the template title, select type, and orientation, upload the background image (it will be a blank page for the background if no image is added).

Click **OK** to confirm.

**UPLOAD** if you have a downloaded file.

![Create a report cover template](/images/kb/103000035042/-j61Az93F112qQdhg4p5eB2x6yEtVXmR0Q.jpeg)

Template created.  
Click the template title or the wizard icon to access the cover wizard page.

![Create a report cover template](/images/kb/103000035042/tY9wIXbsQiQRBTIJxZkDtaAjxQ_pC3mTLA.jpeg)

? Click on the pencil tool (or ⌘/Ctrl 2) to create fields as data boxes by drawing a box on the page.

![Create a report cover template](/images/kb/103000035042/jTyMj9UjOXHMmSRhC0Bc-KGsa6tjy1nUDg.jpeg)

![Create a report cover template](/images/kb/103000035042/CpT0qR0ZZJ8ffscFDMgIiA8W2HgsHSYj5A.png)

Click this icon (or ⌘/Ctrl 4) to bring up **Properties**.

![Create a report cover template](/images/kb/103000035042/MNrWzIOTENRv6BhpQxO-PpyK2i42fBX7jw.jpeg)

In Properties, you may edit the data box attributes and select data types.

Here are the **data types** available:

1.  Drawing _(of where the form is created)_
    
2.  Location _(of where the form is created)_
    
3.  Creation (_of whom generate this report)_
    
4.  [Read only Text _(Preset Text)_](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035063-how-to-set-up-edit-a-preset-text-company-level-)
    
5.  [Read only Image _(Preset Image)_](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000035155-how-to-set-up-edit-a-preset-image-company-level-)
    
6.  Item Count
    
7.  Report Title _(Title of the report rule, such as Form weekly report, Issue daily report, etc)_
    
8.  Report Period _(Date of the period of the report)_
    
9.  Report Conditions _(Condition of the report)_
    

![Create a report cover template](/images/kb/103000035042/5ShYW-9nnYnrhb8uZqyKPU4KythCRwFdLA.jpeg)

On the attributes, you set up the data format and display attributes, such as font size and alignment.

![Create a report cover template](/images/kb/103000035042/Ac0Rhshv-VF_F4_0YMGg_c_4_O5zsmPz0Q.jpeg)

**SAVE** when completed. ??

You may return to the template list by the home button.

![Create a report cover template](/images/kb/103000035042/08lvSN-tQ67vViVz8gM3s9wNQiTuVoQqrg.jpeg)

DONE!! ?
