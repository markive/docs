Data export is a tool for general users to extract data to a CSV file for any purpose.

You can also set up the PDF title here.

Only the company admin can help to create a template as needed.

It is fully customised.

Let see how it work.

First, log in to **Company Area**. _Only the company admin can access this page._

Click **Settings** and select **Data export**.

![How to create a Data export template?](/images/kb/103000035084/kZSOE1NwEklS1NigL6eXl85UwcN2ni1FmA.jpeg)

![How to create a Data export template?](/images/kb/103000035084/FUnRRl_q9foJqOUdGQgM7VnXyoGCoW5E3w.jpeg)

Click the **+** button to add a template

![How to create a Data export template?](/images/kb/103000035084/oOt3vSyLmmzfgHE2JiTL1KXfF-dk1VbjjA.jpeg)

Enter the template title and click **OK** to create.

**UPLOAD** if you have a downloaded JSON file.

![How to create a Data export template?](/images/kb/103000035084/p2cMreilJiJaGEFJj7FRGr0DWqOaEUFH4w.jpeg)

**ADD COLUMN** based on your design, how many columns you would like to have at the CSV file.

and input the column title.

![How to create a Data export template?](/images/kb/103000035084/GRzrY2ZTSb9oys7lKQ2IrIQMGvAcQbF-8Q.jpeg)

Checked the **Include file in export** box if you need to include PDF during download.

![How to create a Data export template?](/images/kb/103000035084/DyFgl3qYsHqEtAFOFGtqBOOppa0gFCo-vg.png)

Click **DATA EXPORT TEMPLATE** to map data when ready.

![How to create a Data export template?](/images/kb/103000035084/IGt0luF6LKGZMASVD8tSFehkCQc4Km6QeQ.jpeg)

Select process template or issue template under the category.

![How to create a Data export template?](/images/kb/103000035084/OHLdRDUWc33flSzQW8yyqGi3_4BwPLCmNw.jpeg)

**ADD FIELD** to map data

![How to create a Data export template?](/images/kb/103000035084/7emwVaGZi5_hdkvaZPi7zndtP27K6ZjQ-A.jpeg)

3 types of data can be selected to add as a field-

1.  [Template Field](#template-field)[](#text)
2.  [Text](#text)[](#attribute)[](#attribute)[](#attribute)
3.  [Attribute](#attribute)

You may combine those for one column.

Click on the logo to select.

![How to create a Data export template?](/images/kb/103000035084/iNsKZSGLs-p73uyMhPu6bp_LGJAFIS8diQ.jpeg)
