Once you've added a user to the Company Level, you may want to add that user to a designated project.

? **via Website**

Click the **≡** Menu icon at the top left corner to unfold the Menu, go to the **Setting** > **Users** page.

![Adding user to a project from the Company level](/images/kb/103000035087/_yeviwJxSMui7bV6Pv3c-e4jDcmCzY5uWA.jpg)

![Adding user to a project from the Company level](/images/kb/103000035087/xC-uRlu3UW5ocXzwAdcJoS3DR0hK9R4AaA.JPG)

Go to that specific user you want to add to a specific project and click on the **⋮** icon.

![Adding user to a project from the Company level](/images/kb/103000035087/3meSfd491Usq0bFCaF_pjUTp12TciRhthg.jpg)

Click **View and add to projects.**

![Adding user to a project from the Company level](/images/kb/103000035087/2_BwxvuvF8P0QizKVWKFPGQiMos3ocbFHw.jpg)

It will then show you what project the user has access to. In this example, the user does not have any access to any project yet. To add project, click **ADD**.

![Adding user to a project from the Company level](/images/kb/103000035087/W5b9gnWtGUg-wr0igSV9S5vH7HuxXm2lHg.jpg)

It will then show the list of available projects. You can search the project from the search bar or you can click the project directly.

![Adding user to a project from the Company level](/images/kb/103000035087/79bJ0g5Q5K9U691TeOOMyx2JtG2g5i5NPg.jpg)

![Adding user to a project from the Company level](/images/kb/103000035087/PGXjNmWbABJ4kA9D8tjutQBczlR2yvAXGg.jpg)

After you've selected the project, choose the team you wish your user to be part of, the list of teams will be shown from dropdown, then click **OK**. User's permission will depend on which team he belongs to, so this needs to be carefully coordinated.

![Adding user to a project from the Company level](/images/kb/103000035087/6hlRGfRiMsn8uGMzisqn4MvscfKB5dPYIw.jpg)

![Adding user to a project from the Company level](/images/kb/103000035087/VVkWecuD85I4NrSvILZxwUMEqk-hk0aeOQ.jpg)

Now, if you check the **View and add to projects** for that user, it will show that he is part of the project. You can add more project if needed by clicking **Add.**

![Adding user to a project from the Company level](/images/kb/103000035087/wOoU3BvwgziPmVjDAUidGHZnPGSMtoU12A.jpg)

![Adding user to a project from the Company level](/images/kb/103000035087/A-7i-3Xs1LKAf4409mnMrSWRgfoslInhjw.jpg)
