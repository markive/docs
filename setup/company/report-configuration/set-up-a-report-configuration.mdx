# Report configuration template

## A template that can set a set of prefilled download options

  

Admin can pair an issue report template with a report configuration template, for the users able to pick a report configuration template from the download process/form/issue dialog. The issue report template will be selected based on the paired report configuration template accordingly.

* * *

First, log in to **Company Area**. _Only the company admin can access this page._

#### Click **Settings** and select **Report configuration.**

![Set up a Report configuration](/images/kb/103000162023/YLuVSlU9oFVAH-lSxOfNLMXQ3y1KrF-j9w.jpeg)![Set up a Report configuration](/images/kb/103000162023/6CYpx8kT2Qu_AtBTe0ANt4tAm5Xfk8Oj6w.jpeg)

  

#### You can create a new template by clicking the **⊕** button.![Set up a Report configuration](/images/kb/103000162023/GhB74kv7oY51PaeblWngxPvFo0I5BGLhtg.jpeg)

Enter the template title, and click **OK** to confirm. 

If you have a downloaded file, you can also click on **UPLOAD**.

![Set up a Report configuration](/images/kb/103000162023/5vcs_olvbZzb_2McrCKHvS5oO2aGWWjZFQ.png)

Template created.

#### The template will be created, and you can now check the download options for this template as pre-fill settings. Any updates made will be saved automatically.

![Set up a Report configuration](/images/kb/103000162023/q09VT3YDq8Fqil2CN_E88l7UwrxzhXZROA.jpeg)

  

Next, you may need to pair this report configuration template with an issue report.

#### Please access the **Report layer** by Company level ➡ Settings ➡ Categories ➡ Subcategories ➡ Issue template ➡ Issue wizard ➡ Report layer to set up.

Here are the screenshots to guide you to access.![Set up a Report configuration](/images/kb/103000162023/nAXkPXb3OtwuguwWdLvDTWGRcmq8JDOORA.jpeg)![Set up a Report configuration](/images/kb/103000162023/QI7UEhZ7GGV_boulaRu4XzlYTpiilTCBaQ.jpeg)![Set up a Report configuration](/images/kb/103000162023/bEmVcExUHCfDuwHrjnK2IWETfCgFfamN2g.jpeg)![Set up a Report configuration](/images/kb/103000162023/PtpInHPIHf3XZqbsGU6Rew1ly1BGSKOS5g.jpeg) Click **Edit**. And select the latest template version which is currently in use, instead of creating a new version.![Set up a Report configuration](/images/kb/103000162023/rlXvLJbblgoFgPMwZXCB_nH30sOA-IPNYQ.jpeg)![Set up a Report configuration](/images/kb/103000162023/u-7j6wS5GQ1YKJ7Jm47hAKDFZlpD_DSNOA.jpeg) Click **EDIT** to access the I**ssue wizard ➡ Report layer.**![Set up a Report configuration](/images/kb/103000162023/Rp2Y7Lm17XQ4lAUEeuxIKli3QvnmSsxlng.jpeg)![Set up a Report configuration](/images/kb/103000162023/T19vI8rH_jN6kqpG-MvDWeLsV4T8353FUQ.jpeg)

#### Select the report layout, click  **⋮**  the button, and **Pair.**

![Set up a Report configuration](/images/kb/103000162023/x858ab1JiOBuIGJ23_-bCTQlQqb8-K3Wdw.jpeg)![Set up a Report configuration](/images/kb/103000162023/jDl8cvH2Y5Ya8bw4nZBQlOjBt096WzbY0Q.jpeg)![Set up a Report configuration](/images/kb/103000162023/mSZd5dylF6Zmp2XYXphyguqvhZt3zH0i_A.jpeg)

Click to select the existing Report configuration template to pair with.

_You can select more than one template according to your needs._

![Set up a Report configuration](/images/kb/103000162023/Xne7iaU4z5Xnv6nuXQnrxI52p3sSHLvXcQ.png)

**OK** to save.

#### ![Set up a Report configuration](/images/kb/103000162023/OuQYDETrCy5yjjNrvo-K9FMVeayS82gsMQ.jpeg)Remember to click the **SAVE** button to save changes.![Set up a Report configuration](/images/kb/103000162023/TK7Zv6k9fy8zX2yoIGFj8Gtgu0Rt49KhWA.jpeg)

* * *

### Set up completed.

* * *

#### Let's check how it works at the Project level.

  

#### Click **Download** to open a download dialog.

#### ![Set up a Report configuration](/images/kb/103000162023/MgQ2fr0lJhpya8hDep_xPl6ZwBmxXepIJA.jpeg)![Set up a Report configuration](/images/kb/103000162023/lIWYgPG8KXHa7YV2-2O9EKBquq0oJLocNw.jpeg)Check the **"Use report configuration template**" option.

If not checked, it will automatically select the default template.![Set up a Report configuration](/images/kb/103000162023/6qVT21qYVAo44eAGo91vntulZHbORPQ-kw.jpeg) 

#### The paired report configuration template has been selected. To download the template, please click on the **DOWNLOAD** button.

  

Once the download is finished, you will have a report with a layout that matches the example provided above, featuring "Photo only".

![Set up a Report configuration](/images/kb/103000162023/NjPKNnGJ1-Eu9ET2w8rOti-BZKUjpeXQmg.jpeg) Alternatively, you can manually select a different template from the available options.![Set up a Report configuration](/images/kb/103000162023/olbfqzfcbYE6o6qHVc41inEf_9jmivMJcg.jpeg) or you can click on the **ADVANCED** button to review and modify the download options.![Set up a Report configuration](/images/kb/103000162023/OFc67C3dlIK2fStWNH5XM_Ciq2oY6eP9vQ.jpeg)![Set up a Report configuration](/images/kb/103000162023/iV5rXraPvl6GlIp29uqwiGx3x-S1MU40eg.jpeg)

Done.
