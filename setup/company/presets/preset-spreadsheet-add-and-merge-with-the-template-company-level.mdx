This article is letting you know how to create a spreadsheet to merge at a computed field of template at the company level, it would be a parameter with project editable.

  

-   [ADD](#%E2%9C%9A-ADD)
    
-   [Merge](#Merge)

  

The sheets in the preset spreadsheet are inserted into the original spreadsheet. If the name of the sheet in the preset spreadsheet is the same as the one in the original spreadsheet, the former replaces the latter.

  

Before starting, please complete the template's computation set-up.

  

[Form template](https://docs.rdrive.io/setup/company/categories/categories-process-template/create-a-process-template-with-form)

[Issue template](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/design-an-issue-record-report-template)

  

We are going to use the spreadsheet sample as same as we use in the article [Computation - Issue](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/computation-issue).

_Click [HERE](https://docs.google.com/spreadsheets/d/1TO1LBKvAHctbn0dvIizYnKNO_uNjlWmJ/edit?usp=sharing&ouid=104843957967887312407&rtpof=true&sd=true) to download the Excel for reference._

* * *

After the computation setting of the issue template is saved, let's move to **Settings** > **Presets** to create a preset spreadsheet for merging with.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/dkPOaBTzLWD0_Q0s4EtPPhQ90fzIKkwIiA.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/9jTAAcIZNDDgDtq7ZrxCzIAzhOlBlTB6yg.jpeg)

Select **SPREADSHEET**

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/Mkg4pn7AHJQcrco2PFpgFxKwu7jJNXMaFQ.jpeg)

## **✚ ADD**

You can create a new preset spreadsheet by clicking the **⊕** button.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/SgYyIsIUmz1NzajFreGD21tCWu6vjqHeRA.jpeg)

To make sure the name of the sheet in the preset spreadsheet is the same as the one in the original spreadsheet, we are going to upload the excel file same as we imported to the issue template.

  

Please click the **⋮** and **Upload** the [excel file you have.](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/computation-issue)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/jUg8_ZYfqjO6x6ewUJyyqgPSRsVS_VMSZQ.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/W26XLdFIxhrS7iS6-P7o-OlQ-hTxzYkD0w.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/IFLSsUAh4bwg-rwFhHWtofGUJ_zkWcqJAA.jpeg)

Spreadsheet imported.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/KfztcRBMUvfCy7SPrgJOHKa6F8gcBBlWzw.jpeg)

You may right-click to Delete the extra sheet if needed.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/5e40q54yK6UkIoG7wU4WkfblsXvjsufJWQ.jpeg)

Leave the sheet with parameters which you may need to edit at the project level.

Click the **⋮** to **SAVE**.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/5QuuoKaz1ZV30aFrc_zUPxfm6IRXfrFmrA.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/ya7t3R4Vxc_XfYpOMh2qyMxe8GR-ShmX_A.jpeg)

Enter spreadsheet title for identification, **OK** to confirm.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/5y-euqS698TEIOAsy6Oi4LmJkds5H-o73A.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/49rkxWfXNGadw9Yu-BfI1th69P5Vq9qycw.jpeg)

Done, you have created a spreadsheet.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/PPa0sKbPo-GUZOjQdEvUMMECv-yuWkJBQw.jpeg)

# **Merge**

Next, please move to the template wizard for merging.

In this example, we are going to merge it to an [issue template's computation.](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/computation-issue)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/tSIsV8ti73aBm3yOvcuYWps_n3hQEQCEwg.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/JP2Ea_SAcVMB3hlW8SotSBbrW0k8NxKfLg.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/19P8YG5fVhH_sVK3c4qNlcSGRg5S3eMGqw.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/jR2Zpnv6G1YeFeI62SDgH9gEXBMjSXqFvA.jpeg)

**⌘/Ctrl 6** or click the **Computation** option from the more tools list  **⋮** to bring up the Computation dialogue.

  

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/-adukSlYw9x3zl9cky0VE_PMoSj-IhOG-Q.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/iqeJhzRx6SNnFmhNgc9RxXXVwVQ7gsQPsQ.jpeg)

Click **EDIT** to open the spreadsheet.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/7CrTS5qT3NQ_xeke1TNTMmWJ3FtlhHbqYw.jpeg)

Click the **⋮** and select **Merge**.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/HfOMfuCsywzYB6yZRT6bzf8fYKF5qoZyNQ.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/VsJ9_O7fDywBlvxgafWic6tRtPQJA3LJuQ.jpeg)

Select the spreadsheet you need to merge with from the dropdown list.

**OK** to confirm.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/z8nTlKE5uIJ_VnqFcW08bIycGoc87Rzz8w.jpeg)

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/DlV65WHhQ71VZNmOB29sBKvbpF1onPMWag.jpeg)

It will automatically save. Click **x** to exit.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/o0eMeSMZfr65gvO4PXFZOf0WLInJSyX5mg.jpeg)

**OK** to save changes.

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/KkzuZjqeKduzw5upnpIZ-KJKPTc1Qo74sg.jpeg)

**SAVE.**

![Preset Spreadsheet - Add and Merge with the template (Company level)](/images/kb/103000035012/xA0ARO88tVebIjoauFr_otA3xSI7O6ygFg.jpeg)

<Note>
⭐️ Remember to PUBLISH the template after changed!!
</Note>
