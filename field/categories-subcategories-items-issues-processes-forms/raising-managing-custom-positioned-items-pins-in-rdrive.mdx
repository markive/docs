### **Overview**

Custom Positioned Items allow you to record Issues and Processes at a precise position on a project drawing.

  

Unlike a Location-based Item, which is associated with a Location, a Custom Positioned Item is given a specific X/Y coordinate and appears as a **pin** on the drawing.

  

Pins provide a visual way to see where Items are located and their current status.

  

This guide explains how to raise, find, view and manage Custom Positioned Items in RDrive.

  

-   **Purpose:** Learn how to raise and manage Custom Positioned Items (pins) on project drawings. 
-   **Who It’s For:** Project users who need to raise or manage Items at specific positions on drawings. 

  

<Note>
Prerequisites: Access to an RDrive project, the required Drawing and Locations, and permission to create or manage the relevant Item type
</Note>

  

<Note>
New to Items? See Understanding Items in RDrive for an introduction to Issues, Processes, Location-based Items and Custom Positioned Item
</Note>

## **Raising & Managing Custom Positioned Items**  

_Raise an pin on the app, add a photo, find the Issue again, add a comment and progress its status._

# **What is a Custom Positioned Item?**

A **Custom Positioned Item** is an Issue or Process placed at a specific X/Y coordinate on a project drawing.

The Item appears as a **pin** at the selected position.

  

Custom positioning is useful when the exact position of the Item is important.

For example:

-   A defect on a wall
-   Damage to a specific door
-   An observation at a particular point
-   A fire door or other asset
-   An inspection relating to a specific installation
-   A Process associated with a precise area of work

  

Both **Issues** and **Processes** can be Custom Positioned.

  

# **Understanding Pins**

The **pin** is the visual representation of a Custom Positioned Item on the drawing.

Its position shows **where the Item is located**.

Its colour represents the **current status of the Item**.

  

This allows project teams to review a drawing and quickly identify where Items have been raised and their current progress.

  

<Note>
Good to know: Statuses, workflows and pin colours can vary depending on how your RDrive project has been configured.
</Note>

## **Raising a Custom Positioned Item** 

Custom Positioned Items are raised directly against a project drawing.

  

**Raising an Item from the Location**

  

**_\[VIDEOPLACEHOLDER – Selecting a Location and placing a pin on the app\]_** 

1.  From the main menu, open **View Plans**.
2.  Navigate to the required **Drawing**.
3.  Select the relevant **Location**.
4.  Select **+** to add a new Item.
5.  Select the required **Issue or Process**.
6.  Select the position on the drawing where the Item should be located.
7.  Confirm the position of the pin.
8.  Complete the required Item information.
9.  Add photographs or supporting information where required.
10.  Complete all mandatory fields marked with **\***.
11.  Select **Save**.

  

The Item will now appear as a pin at the selected position on the drawing.

**Raising an Item Using Add Item**

  

You can also start by selecting **\+ Add Item** from the Plan Viewer.

1.  Open the required Drawing.
2.  Select **\+ Add Item**.
3.  Select the required Item type.
4.  Select the Location the Item relates to.
5.  Position the pin at the required point on the drawing.
6.  Complete the Item information.
7.  Save.

<Note>
Tip: Particulary useful if your drawing is particulary busy with items
</Note>

## **Moving a Custom Positioned Item (Pin)**

If you place a Custom Positioned Item in the wrong position on the drawing, you can move the pin to the correct position **before the Item has been synchronised**.

Moving the pin changes its X/Y position on the drawing. It does not change the Item's Location or the information recorded against it.

  

<Note>
Important: You can only move a newly raised pin on the mobile app before you synchronise your device.
</Note>

##   

## **How to Move a Pin** 

  

  

1.  **Long Press the Pin to open the menu**
2.  **Open the Menu and Select Move** 
3.  Drag the pin to its correct position on the drawing.
4.  Select **PLACE** to confirm the new position.

The Item will now appear at its new X/Y position.

  

<Note>
Can't see the Move option? Check whether the Item has already been synchronised. Once synchronised, the pin can no longer be moved using the mobile app.
</Note>

  

# **Removing a Custom Positioned Item**

If you raise a Custom Positioned Item by mistake, you can remove it from the mobile app **provided it has not yet been synchronised**.

  

  

<Note>
⚠️ Important: Deleting an Item cannot be undone. Make sure you have selected the correct Item before confirming.
</Note>

  

<Note>
Tip Deleting an Item from the Mobile App can only done before synchronised. Once the Item has been synchronised, it can no longer be removed from the mobile app. A synchronised Item must be removed using RDrive Web, subject to the user's permissions.
</Note>

  

**How to Remove an Item Before Synchronising**

  

1.  **Press and hold the pin** to open the Item menu.
2.  Select **Delete**.
3.  Select **OK** to confirm.

  

The Item and its pin will be removed.

<Note>
⚠️ Once the Item has been synchronised, it can no longer be removed from the mobile app. A synchronised Item must be removed using RDrive Web, subject to the user's permissions.
</Note>

## **FAQs & Troubleshooting**

**Q: Is a pin always a defect or snag?**   
**A:** No. A pin represents a **Custom Positioned Item**, not necessarily a defect.

It could represent an Issue such as a defect, snag or observation, an asset record such as a fire door or sprinkler, or a Process such as an inspection or installation.

  

**Q: Can both Issues and Processes be raised as pins?**   
**A:** Yes. Both **Issues and Processes** can be Custom Positioned and appear as pins on a drawing.

  

**Q: Does every Item need to be positioned as a pin?**   
**A:** No. Items can either be **Location-based** or **Custom Positioned**.

A Location-based Item is associated with a Location without having a precise position on the drawing. Use a Custom Positioned Item when identifying the exact position is useful.

  

**Q: What does the colour of a pin mean?**   
**A:** The pin colour represents the **current status of the Item**.

The statuses and colours available will depend on how your RDrive project and Item types have been configured.

  

**Q: Why can't I see the Item I want to raise?**   
**A:** The Items available to you depend on your **Team, permissions and project configuration**.

If you expect to see an Item type and it isn't available, contact your Project Administrator.

  

**Q: What's the difference between raising from a Location and using Add Item?**   
**A:** Both methods create the same Custom Positioned Item.

**Select the Location first** when you already know where the Item belongs.

**Add Item** can be particularly useful on busy drawings, allowing you to select the Item and Location before positioning the pin.

**Q: Can I raise more than one similar Item quickly?**   
**A:** Yes. After raising your first Item, use **Quick Add** at the bottom-right of the screen.

Quick Add allows you to create another Item of the **same type against the same Location**, reducing the number of steps required when raising several similar Items.

  

  

**Q: Can I change the position of a pin if I put it in the wrong place?**   
**A:** Yes, provided the Item **has not yet been synchronised**.

Before synchronising, you can move the pin to the correct position. Once the Item has been synchronised, it can no longer be moved from the mobile app.

  

**Q: Can I remove an Item I've raised by mistake?**   
**A:** Yes, provided the Item **has not yet been synchronised**.

Once an Item has been synchronised, it cannot be removed from the mobile app and must be removed using **RDrive Web**, subject to your permissions.
