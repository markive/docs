### **Overview**

_How to view an issue, defect or record using RDrive using the desktop/browser_

-   **Purpose:** How to view an issue, defect or record against a location on the desktop
-   **Who It’s For:** General users

<Note>
Prerequisites: Able to raise an issue, defect or record from the desktop/browser
</Note>
