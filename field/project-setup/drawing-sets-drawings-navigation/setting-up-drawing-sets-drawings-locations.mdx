### **Overview**

Drawings provide a visual representation of your project, allowing issues, forms and tasks to be pinned to their exact location. Before work begins on site, it's recommended that you set up your Drawing Sets, upload your Drawings and create your Locations so your team can immediately start recording information in the correct place. 

  

**Structure**

├── Drawing Set

│     ├── Drawing

               ├── Locations

  

**For Example**

├── Floor Plans

        ├── Ground Floor

                ├── Apartment 101

                ├── Apartment 102

                ├── Corridor

                ├── Stairwell

  

By completing this setup you will:

-   Organise drawings into Drawing Sets
-   Upload project drawings
-   Add project Locations to each drawing
-   Prepare the project so issues, inspections and the like can be linked to the correct areas

  

-   **Purpose:** Project Administratos
-   **Who It’s For:** 

<Note>
Prerequisites: Part of the Project Admin team with Drawings/Loctions Role
</Note>

## **Step-by-Step Instructions**

### **✅ Step 1: Create Drawing Sets** 

Drawing Sets work like folders, allowing you to organise drawings into logical groups.

For example:

-   Site Plan - External Works
-   Floor Plans
-   Elevations

Drawing Sets also make it easier to:

-   find drawings
-   generate filtered reports
-   manage drawing updates

  

1.  To create a Drawing Set:
    
    1.  Open **Settings → Drawings**
    2.  Click the **+** button
    3.  Enter the Drawing Set name
    4.  Select **OK** to save it. 

  

**Re-ordering you Drawing Set**

To re-order the Drawing Set simple drag the Burger Menu up or down

  

**Editting your Drawing Set**

If you need to re-name the drawing set simple select the set and change the title name

  

### **✅ Step 2: Upload Drawings** 

**What is a Drawing?**

  

A **Drawing** is a digital version of your project plans that provides the visual layout of your building or site.

Drawings allow your project team to:

-   Raise Issues at the correct location
-   Complete Processes and inspections against specific areas
-   Navigate the project visually
-   Record exactly where work has taken place

  

Once your **Drawing Set** has been created: 

1.  Select the required Drawing Set. 
2.  Click the **+** button in the bottom-right corner. 
3.  Drag and drop your drawing file(s) or browse to select it.
4.  Wait for the upload to complete.

  

<Note>
Tip: The drawing name will automatically use the uploaded file name, although it can be edited later if required.
</Note>

  

**Editting your Drawings**

After a drawing has been uploaded, it can still be managed from Settings → Drawings -> Select in **Browse Mode** \-> Select the Drawing Menu

  

**Re-ordering your Drawings**

To re-order you Drawing change your viewing mode from **Browse to Sort** this will allow you to short the drawings

  

### **✅ Step 3: Add Drawing Locations**

Locations become the common reference throughout the project. Issues, Forms, Tasks, Assets and Progress Monitoring all use the same project locations, so taking time to configure them correctly at the beginning avoids duplicate work later. 

  

Examples include:

-   Apartment 101
-   Bedroom 1
-   Plant Room
-   Corridor A
-   Office 12

Rather than simply dropping an issue onto a drawing, assigning it to a Location allows:

-   accurate reporting
-   location-based filtering
-   progress monitoring
-   easier searching

  

To add locations to your drawings, firstly navigate to the Drawings by either

1.  Select the drawing edit and selecting View -> Plan View
2.  From the Plan Viewer -> Search 'Drawing' -> Select your drawing

  

  

Once you have the Drawing 

1.  Click the **+** button.
2.  Choose **Location**.
3.  Place the pin on the drawing.
4.  Enter:

-   Location Name
-   External Reference (optional)
-   Tags (if used)

  

<Info>
What is the External Reference? An External Reference is an additional identifier that helps further distinguish between locations. For example, it can be used to: Link Room Data Sheets or other external documents to specific locations. Assign different names for the same location, such as using one name from the architect and another from the construction company. This feature helps ensure clarity when multiple naming conventions are involved in a project.
</Info>

  

<Info>
What is a Location Tag Can be a condition of access on read, edit, delete of Location and all rules of Drilldown, Process, and Issue. Also, it can be used on the Report policy and Subscription policy as a condition on the rule.
</Info>

  

**Batch Upload Locations**

For larger projects, manually creating hundreds of rooms can be time consuming.

1.  Open the drawing in the Plan Viewer.
2.  Click **\+ → Location**.
3.  Download the Location Template.
4.  Complete the Excel spreadsheet with all location names.
5.  Upload the completed template.
6.  The locations will appear in a list.
7.  Simply click each location and place its pin on the drawing.

This approach significantly speeds up project setup, especially for residential and commercial developments.

  

  

### **✨Best Practice**

For the most efficient project setup:

1.  Create all Drawing Sets.
2.  Upload all project drawings.
3.  Import or create all Locations.
4.  Review each drawing to ensure locations are correctly positioned.
5.  Only then begin raising Issues and completing Processes.

This ensures every issue, inspection, form and report is linked to the correct project location from day one.

## **FAQs & Troubleshooting**

**Q: Can I edit my drawing once uploaded?**  
**A:** Yes. After a drawing has been uploaded, it can still be managed from **Settings → Drawings**.

  

**Q: Can I edit my locations once uplaoded?**  
**A:** Yes. Select the location and select Edit
