## **Introduction**

Preset spreadsheets are powerful tools for managing data and customizing projects efficiently. This article provides a practical guide on how to use preset spreadsheets effectively, with a focus on maintaining data integrity and project flexibility.

### **1\. **Data-Only Usage****

### Preset spreadsheets should be exclusively used for storing data. Avoid including formulas in them for the following reasons:

-   **Data Integrity**: Keeping data separate from formulas minimizes the risk of unintentional changes to critical information.

-   **Clarity**: Using preset spreadsheets solely for data improves project organization and simplifies data management.

-   **Lookup Efficiency**: Dedicated data tables in preset spreadsheets make it easier to access and reference information, reducing errors.

### **2\. **Project-Level Overrides****

### Preset spreadsheets can also be used for project-level customizations. Follow these guidelines for effective use:

-   **Isolate Overrides**: Create a separate preset spreadsheet for project-level overrides to prevent interference with your primary data.

-   **Reset Functionality:** A noteworthy feature is that preset spreadsheets often include a reset option that allows you to return data to the default, effectively resetting it to match the company-level settings. This can be a valuable tool when you need to revert to the standard configuration.

## **Conclusion**

Preset spreadsheets are valuable assets for data management and project customization. Keep them data-focused, avoiding formulas, to maintain data integrity. Utilize them for project-level overrides with care, documenting changes, and ensuring consistency. Following these best practices will improve efficiency and reduce the risk of errors in your projects.
