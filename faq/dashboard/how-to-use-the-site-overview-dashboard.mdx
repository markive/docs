### **Overview**

_This guide walks you through how to filter and export data from the register on the Site Overview dashboard in RDrive. This process is useful for generating tailored reports and conducting data analysis efficiently._

-   **Purpose:** To help users extract specific data from the Site Overview dashboard for reporting or analysis purposes.
-   **Who It’s For:** Hong Kong DWSS users with access to the Site Overview dashboard.  
      
    

<Note>
Prerequisites: Access to the RDrive Site Overview dashboard.
</Note>

* * *

In this guide, we'll walk you through the process of filtering and exporting data from the register at the Site Overview dashboard. This is a simple yet powerful way to extract the data you need for further analysis or reporting.

#### Step 1: Filtering the Data

To begin, you'll need to filter the data based on the process type:

-   **Select the Process Type:** Click on the desired type directly in the "Outstanding Chart" on the Site Overview dashboard. This helps you narrow down the register data to only the relevant records.![How to use the Site overview Dashboard?](/images/kb/103000035027/ryQWf2m8QIYDD3KYpUWHA9DTFV0Ut5nzgQ.png)  
    
-   **View the Filtered Data:** After selecting the process type, click the **"VIEW REGISTER"** button. This will apply your filter and display the relevant data in the register.![How to use the Site overview Dashboard?](/images/kb/103000035027/DMeINwyrjGeC3uNbNTCmEPtkCvTDcGSfvg.png)![How to use the Site overview Dashboard?](/images/kb/103000035027/dt-M85-1wqG9ij2RlGva-wsnSMX5maWNCw.png)
    

#### Step 2: Exporting the Data

Once you have the data filtered to your needs, you can proceed to export it:

-   **Access the Export Option:** Move your cursor over the table displaying the filtered data. A "..." icon will appear in the top right corner of the table.![How to use the Site overview Dashboard?](/images/kb/103000035027/0xzHV1Q8V6H0iHGi-HfYVgPBO2yzNH5Wmw.png)
    
-   **Export the Data:** Click on the "..." icon and select the **"Export Data"** option. This will bring up the export menu.
    
-   **Download the Data:** Click **"EXPORT"** to start downloading the filtered data. The file will be saved in the default location on your device, ready for further use or analysis.  
    ![How to use the Site overview Dashboard?](/images/kb/103000035027/GCbegNTmTthKrcHgB3UqGtkw2Rf8o3yg8Q.png)![How to use the Site overview Dashboard?](/images/kb/103000035027/XUxoQJ-nIgM4Z0uX2-d-Ye7MhrwvLSvoyQ.png)

# Conclusion

By following these simple steps, you can quickly filter and export the data you need from the Site Overview dashboard. This feature makes it easy to extract specific data sets, allowing for more efficient data management and reporting.

Make sure to leverage this capability whenever you need precise data extraction from your registers!
