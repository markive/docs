### **Overview**

_How to search for data effectively within RDrive using the browser/website_

-   **Purpose:** How to use the universal search bar in RDrive and defining OR AND conditions
-   **Who It’s For:** General users

<Note>

From the universal search bar at the top of the screen when using the website, we can filter and show information to suit our needs, with the ability to layer multiple filters to refine your search.  
  
The "Conditions" help define how the search happens, and are broken up into 2 different conditions, providing the flexibility of utilizing `AND` / `**OR** to give you specific data instantly.`

-   [Adding OR Conditions](https://docs.rdrive.io/faq/general/mastering-universal-search-flexibility)
-   [Adding AND Conditions](https://docs.rdrive.io/faq/general/mastering-universal-search-flexibility)

  

# Universal Search

To refine search results, multiple criteria, and conditions can be added.

## Adding `OR` Conditions

When employing the same criteria with different conditions in Universal Search, the results are amalgamated using the `OR` logic. For example:

-   **Status:** `{Status title}` ; **Status:** `{Status title}` ; **Status:** `{Status title}`

This will generate results for all specified statuses.

![Mastering Universal Search Flexibility](/images/kb/103000255360/Ckg0rrUCzZ9mGb7p3hqZgnuJZCbhw-L4Mw.png)

* * *

## Adding `AND` Conditions

Utilizing different criteria with any conditions in Universal Search invokes the `AND` logic, returning results that meet all specified criteria. For example:

-   **Drawing:** `{Drawing title}` ; **Status:** `{Status title}` ; **Created by user:** `{User name}`

This will filter results that satisfy all given conditions.

![Mastering Universal Search Flexibility](/images/kb/103000255360/ij271aM_BJp-ynTfxj2tfHR_RAF_g8VaIQ.png)  

<Note>
Exception - Created date Created date has a sub-condition of 'to' and 'from.' It returns results within the date range (AND) by applying the same criteria with different date conditions.
</Note>
