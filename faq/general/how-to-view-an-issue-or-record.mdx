### **Overview**

_A brief introduction explaining the purpose of this guide._

-   **Purpose:** To locate and review previously raised issues or records
-   **Who It’s For:** Any user with ready only access and above

<Note>
Prerequisites: Existing issues raised on the project
</Note>

* * *

## **Step-by-Step Instructions**

### **✅ Step 1: Accessing the Finder**

1.  From the main menu, tap the menu icon (≡) in the top left corner.![How to View an Issue or Record](/images/kb/103000360436/ciFPUEQwGvGOZOqT6Xsj_O5rpAg_gOEVYA.png)
2.  Select the relevant Subcategory Finder for the type of item you're trying to locate.![How to View an Issue or Record](/images/kb/103000360436/Ghoh-x_CQokj53Tvyp7qwPrDDUh8pgQg_Q.png)
    

### **✅ Step 2: Searching for a Specific Issue or Record**

1.  Tap the magnifier icon in the top right corner to open the search panel.![How to View an Issue or Record](/images/kb/103000360436/vmK1oqqXH_OQjDZHJjCQ39y97LGlwqVqvw.png)
2.  Apply search filters such as location, status, or assigned user to narrow results.![How to View an Issue or Record](/images/kb/103000360436/DBCZIYVj8GThVMPQEncO2BJEFVbqQ24MaA.png)
    
3.  Select the magnifying glass to apply the search. Results matching your criteria will appear in the list.![How to View an Issue or Record](/images/kb/103000360436/whnbgSIUmyzT2_zTOLniSeWUePpgveDtAQ.png)
    

## **Step-by-Step Instructions - Using the Plan Viewer**

### **✅ Step 1: Accessing the Plan Viewer**

1.  From the main menu, select Plan Viewer.
2.  Navigate to the relevant drawing or floor using the drilldown navigation.![How to View an Issue or Record](/images/kb/103000360436/1vqn__WXK-2zzH7Y-GWOxyW_CIz8-7Y3pQ.png)
    

### **✅ Step 2: Viewing a Record on the Drawing**

1.  Locate the blue pins on the drawing; these indicate placed issues or records.
2.  Tap on a pin to view full details of the record or issue placed at that location.
    
3.  You can view descriptions, photos, status, and other associated metadata.![How to View an Issue or Record](/images/kb/103000360436/koDPiGRnnbnFQMgJ0krDdfGfd-fP0EZ6Hw.png)
    

### **✅ Step 3: Saving Filters as a Bookmark (optional)**

1.  After applying filters, you can save this selection for future access.![How to View an Issue or Record](/images/kb/103000360436/JXN4bII2_leS-mYSEwHlaCgvXXWonHudzg.png)
2.  Tap “Bookmark” to name and store your filter configuration.![How to View an Issue or Record](/images/kb/103000360436/7iBO37l59ufuO-Jfyp9XjdqRsXUhe-idZQ.png)
    
3.  Click the "+" to add a new bookmark.![How to View an Issue or Record](/images/kb/103000360436/UqAuMIZe8hll7G2K3c3kFtKyX_S7Ei56cg.png)
    
4.  Add a title for the bookmark and select "Save".![How to View an Issue or Record](/images/kb/103000360436/Lqd2jt1pY79xsgLpBuKKFJkxjbmjtbZLMw.png)
    
5.  This will now show in the bookmarks section and will apply the set filters for quick access to this information again.

## Best Practices & Tips

-   Use Finder for a structured, searchable view when managing a large volume of items.
-   Use the Plan Viewer for a spatial overview of where issues are located.
-   Always apply filters for faster access to relevant records.
-   Bookmark frequently used searches for efficiency.

## FAQs & Troubleshooting

**Q: Can I search for issues based on specific fields like assignee or status?**

**A**: Yes. Use the magnifier icon in the Finder to apply various filters.

**Q: How do I know where a record is located on the plan?**

**A**: Use the Plan Viewer to navigate to the drawing and tap the pin to view location-based records.

**Q: What's the benefit of using bookmarks in the Finder?**

**A**: Bookmarks save your filter selections so you can quickly repeat searches without reapplying filters.
