---
title: "How to reset the password for the user?"
description: "Only the company admin can reset the password for all users."
---

Only the company admin can reset the password for all users.

**via Website**

click the **≡** menu icon on the top left corner to unfold the Menu, get entry to the **Setting** > **Users** page.

![How to reset the password for the user?](/images/kb/103000035142/JuOHnirtGF34td3cYruhez1HeWnP0HY0BA.jpeg)

![How to reset the password for the user?](/images/kb/103000035142/AfufiC64BS6jpZsVTbnYJSCQPzulJX-gOA.jpeg)

Click the **⋮** button on the right-hand side of the user detail > **Change authentication settings**

![How to reset the password for the user?](/images/kb/103000035142/B8Z5Tw_bUao1hKf8YAaVUklVC-TKtXBydQ.jpeg)

![How to reset the password for the user?](/images/kb/103000035142/pj2JtT_e7LBc0m4TXM6YTwccRXHbxOSsdQ.png)From here you are able to reset the password.

Please check the Reset password box and enter the new password twice.

![How to reset the password for the user?](/images/kb/103000035142/muAVxTPQoVI7o8AU4ZEN9popWhk59GOHuw.jpeg)

Click **OK** to save.
