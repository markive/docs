# **Overview**

Tags and Presets are an important part of setting up Progress Monitoring correctly.

  

They provide the structure that allows RDrive to identify, organise and report on Progress Monitoring data across your **Company, Projects, Schedules and Dashboards**.

  

Correct configuration is particularly important where:

-   Multiple schedules are being managed
-   Different projects use different programmes
-   Progress needs to be filtered or reported separately
-   Dashboard reporting is required
-   Schedule information needs to be consistently identified across projects

  

Level

Purpose

**Company Level**

Create the required Presets and define the standard configuration available to projects.

**Project Level**

Populate those Presets with the values applicable to the individual project.

**Schedule**

Apply the required Tags to identify the schedule for Progress Monitoring and link it to the corresponding Schedule Code held within the Project Presets.

**Reporting**

Uses the configured project items, schedule and tagged data to display the relevant Progress Monitoring information.

  

Tags are then used to identify the relevant **Schedule Templates, Schedules, Processes and Issues** that belong to the Progress Monitoring configuration.

The required Presets must first be created at **Company level**.

  

These create the fields that will later be populated against individual projects.

For projects using more than one schedule, separate Presets are required for each schedule.

# **FAQs & Troubleshooting**

**Q: What if my project has more than one Schedule?**   
**A:** Create a separate set of Schedule Presets for each Schedule, including its Code, Planned Start Date and Planned End Date. Each Schedule Code must match the corresponding Schedule Tag. 

  

**Q: Why is my Schedule not appearing correctly in Progress Monitoring?**   
**A:** Check that the Schedule Code populated in the Project Preset exactly matches the Tag applied to the Schedule

  

**Q: Do I create the Presets separately for every project?**   
**A:** No. Presets are created at Company level and then populated with the appropriate values at Project level. 

  

**Q: Can two Schedules use the same Schedule Code?**   
**A:** No. Where multiple Schedules are being tracked within the same project, each Schedule should have its own unique code so that RDrive can identify them separately. 

  

**Q: What if my project has more than one Schedule?**
