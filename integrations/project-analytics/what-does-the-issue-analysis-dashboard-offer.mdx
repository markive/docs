### **Overview**

  

The **Issue Analysis Dashboard** provides a comprehensive, real-time view of project wide issues and activity. 

Offering cutting-edge project management and issue monitoring. 

The issue analysis dashboard will help take your projects to the next level of monitoring, that will allow you to manage your projects by region, sector, etc and help you stay in control of project progress.

  

### **Key Features of the Issue Analysis Dashboard**

-   **Project Wide Overview:** Gain a comprehensive snapshot of your projects, broken down by region and sector. Instantly identify if your project is on track and or if it requires additional attention.
-   **Breakdown your issues by region / sector:** Drill into detailed views of issue volume, type and resolution times. Filter by location, category, or team to uncover insights specific to your needs.
-   **Team progress and schedule insights:** Monitor team performance in real time, tracking tasks and whether they are on schedule versus those that are falling behind.
-   **Interactive drilldown functionality:** Click any visual or metric to access detailed data, timelines, and issue history, allowing you to navigate seamlessly to the root cause and take informed next steps.
-   **Real visual data now:** Choose how you see your data - From summary charts to bar graphs. View project metrics in the format that best supports your workflow.

**Functions and Uses within the Issue Analysis Dashboard**

  

The **Issue Analysis Dashboard** provides additional tools to help navigate and make the most of your data, from searching for specific issues to running reports on your issues and teams. Lets look into some of the additional functionality available within the Issue Analysis Dashboard.

  

**Filtering**

  

**From the Menu Bar**

You can filter your results on the project from the Issue Analysis dashboard in a few ways, from the menu bar between Overview, Drawings and Analysis.

  

![Issue Analysis](/images/kb/103000361294/2KtvssmSpfMwq_tPM329N0wDPnAJ-X2u6A.png)

  

### **Filtering By Status**

From the "Drawings" tab on the main menu bar there is a "Due By Analysis" section. Here you are able to filter issues by their status. You can select the required statuses by click the "x" on those that are not required and adding those from the dropdown that are required.

  

![Issue Analysis](/images/kb/103000361294/cp_TqwrKbuJAEREgrtyj6U-Y9Ct1PhzVcg.png)

  

### **By the Issue Grid Search bar**

From the Issue analysis dashboard scroll down on any page to access the "Issue Grid". This will show a full list of issues within this project, whilst searching / filtering can be achieved in the search box in the top right. This will match issues based on their ID, Issue Details, Location, status and assignment team.

  

![Issue Analysis](/images/kb/103000361294/22bQs44tltNtaeRjVbxngwOk4H4qhX_53g.png)

Once you have selected download within the Issue Grid you can then further define how and what data you would like to see in the report.

  

### **Downloading your Data**

  

**\-Visual Data and Graphs**

  

There is a raft of useful data available for download within the issue analysis dashboard, from visual graph data for the Burnup and Issue Grid reports, which will only download the image graph as it is at the time of downloading and defined by the selected time period.

![Issue Analysis](/images/kb/103000361294/vXXh0LyUCW353pMwZpq57xuEWMFrUDwccA.png)

  

**\-From the Issue Grid Data Table**

  

When selecting the download arrow within a data table such as the "Issue Grid" you will have the option to select what data and how the information is presented, simply select the file type and page format you wish to download this data in.

**_![Issue Analysis](/images/kb/103000361294/K30FH2iRBaKR1br_SgeRC8OsdKthb2HVGQ.png)_**

  

Once you have selected download within the Issue Grid we can then further define how and what data we would like to see in the report. 

This can then be filtered through the "Group by" and "Order by" fields below.

**Visibility of Overdue Issues**

From the Issue Grid, we can also see issues due date, when this was due by and how many days the issue is overdue. Using the search bar will also filter these issues by your search criteria and reflect in the item grid below.

![Issue Analysis](/images/kb/103000361294/DOvnRVdcJUtWMNR350HqgN5LRXBHeryY5w.png)

The "Due By" column within the issue grid shows items overdue from their priority expected completion date, allowing you to see at a glance or in detail items falling behind within the project.

  

  

## **FAQs & Troubleshooting**

**Q: Does removing an issue from the dashboard delete it from the project?**  
**A:** No, the dashboard only reflects the data stored in the system. If you filter or hide issues, they are not deleted. To remove an issue permanently, it must be deleted from the main project records.

**Q: Can I export the Issue Analysis Dashboard data?**  
**A:** Yes, you can generate time-bound reports directly from the dashboard modules, including issue lists and activity summaries. These reports can be downloaded for sharing or offline review.

**Q: Why don’t my dashboard metrics match the project data I see elsewhere?**  
**A:** This usually happens due to filters applied (e.g., by date range, team, or category). Check your filters and refresh the dashboard to ensure you’re viewing the most up-to-date information.

**Q: How do I drill down into specific issue details?**  
**A:** Click on any chart element, metric, or status category. The dashboard will expand into a detailed issue list, showing responsible parties, due dates, and related information, this will actively redraw the issue grid to this filter in real time.

**Q: Can I monitor performance by team or region?**  
**A:** Yes, the dashboard allows you to break down data by team, region, sector, or priority, making it easy to track workload distribution and performance.

**Q: What should I do if the dashboard is not loading or showing incomplete data?**  
**A:** First, refresh the page or clear filters. If the issue persists, log out and back in to the platform. For ongoing issues, contact support with screenshots and details of the problem.
