---
title: "Can I delete a process? (APP)"
description: "Before you synchronise the RDrive app, you can delete process(es) you just newly created."
---

**Before you synchronise the RDrive app**, you can delete process(es) you just newly created.

**After you synchronise the RDrive app**,

1️⃣ You will not be able to delete newly created process(es) you created on RDrive app.

2️⃣ Synchronised process can only be deleted if an user is given with "Delete" permission. Normally, only project administrators can delete process(es).

<Note>
Deleting anything on RDrive is irreversible. You are not able to rollback the delete action.
</Note>

* * *

If you would like to delete process(es) you newly created on RDrive app before synchronisation, here are the steps:

First of all, search the unsynced process you would like to delete through Finder

<Info>
How do you know a process is unsynchronised?

Unsynchronised process(es) do not have Process Profile ID assigned to it. The ID will only be assigned once it is synced.
</Info>
