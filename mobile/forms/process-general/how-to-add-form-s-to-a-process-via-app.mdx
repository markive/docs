You may have to add optional form(s) to existing process due to operational needs.

  

This article is going to show you how to add optional form(s) on RDrive app?

  

First of all, access to the process.

![How to add form(s) to a process via APP?](/images/kb/103000035205/92DabZQMhjBCsYKPDQ_G4RZRnuNA29SF7g.jpeg)

Once you get to the process, click the "+" button at the bottom right corner.

  

<Note>
Opps! Cannot see the "+" button? Not everyone can add an optional form! Probably you do not have the permission to add it. Please reach out to your project administrator for more details.
</Note>

![How to add form(s) to a process via APP?](/images/kb/103000035205/NbNseL0r1nNdGQ5sce1e2nVMr6wMOmBdHw.png)

  

Choose the form template that you would like to add to the process
