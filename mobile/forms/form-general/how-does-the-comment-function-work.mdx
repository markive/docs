## **Getting tired of using online messaging app / email / telephone to communicate on the work progress of a process/form? ?**

  
On RDrive, there is a comment function for you to leave a comment to your co-workers. An email notification will send to an user if you @mention him in the comment. You can make use of this function to achieve different purposes! There are plenty of possibilities! Explore it! 

To add a comment to a form, here are the steps:

Go to Finder and access to the process and form.

![How does the comment function work?](/images/kb/103000035162/4EnUqMsFkK74trfWX7JpKD_yVeOmSx1uoA.jpeg)

![How does the comment function work?](/images/kb/103000035162/MW--dtChrtAjxLAmTQipVbJlXXzMgiu4pA.jpeg)

![How does the comment function work?](/images/kb/103000035162/VNiYC540bMaifPf7Y_vSbFVUrTmOEn5BFw.jpeg)

A form is now opened in the form viewer, click ⋮ to select "Comment"

![How does the comment function work?](/images/kb/103000035162/EZEP2IKxSYB-70je48t-IJcuu9R1wrOeFw.jpeg)

![How does the comment function work?](/images/kb/103000035162/_AbJLjk9bfGdh9NTkuRz7_72og6DnOyg5A.jpeg)

Click "**+**" button to add a comment

You can either

  
1️⃣ Simply leave a comment  
2️⃣ Leave a comment and @mention user by clicking notify user icon

![How does the comment function work?](/images/kb/103000035162/FkpD4wyuY0Y6qwfH_0CH2KEa9nsnsMeTDg.jpeg)

If you go for 2️⃣ , once user(s) is picked , click "**OK**"

![How does the comment function work?](/images/kb/103000035162/esSwj6a7hVhTfI7Vg97ZmCYTV607caVpug.jpeg)

When you finish entering your comment, click "**Comment**" to save

![How does the comment function work?](/images/kb/103000035162/lwlMgGu1Wg-QGfl2Kl_L6gyRoSkafFd8QA.jpeg)

![How does the comment function work?](/images/kb/103000035162/POaJP8t3rrJ5yVohamXAS7XBrTbHtikS_Q.jpeg)

  
You can edit and delete the un-sync comment.

<Info>
Once it is synced, the comment is unable to be edited and deleted.
</Info>

![How does the comment function work?](/images/kb/103000035162/833WUEN63PEiMHyfxZ2MTdX3Fq4YvSO-HA.jpeg)

After it is synced, the user(s) you picked will receive an email / app notification!

<Note>
⚠️ After completing your onsite work, don't forget to synchronize. This action ensures data backup and updates for your project team.
</Note>
