Users can automatically fill in multiple fields by scanning the QR code via the app when utilizing the QR code import template. If you wish to use this feature, kindly request the Company admin to set up the template for you.

<Info>
Note: This functionality is not applicable to image, checkbox, pass/fail/NA, and signature field types.
</Info>

If you're the Company admin and unsure about setting up the QR code import template, check the instructions [HERE](https://docs.rdrive.io/setup/company/categories/categories-issue-record-template/how-to-add-qr-code-import-template-to-an-issue-record).

Additionally, you can fill in the text fields and external references by scanning a QR code without using any import template. Learn how to do it [HERE](https://docs.rdrive.io/mobile/general/scanning-qr-code-to-input-text-and-ext-reg-field).

* * *

To begin, please [access the form viewer to edit](https://docs.rdrive.io/mobile/forms/form-viewer-edit-change-status/how-to-edit-form-content-via-the-app). 

Click ⋮ and select the **QR Code**. 

![Scanning QR code to fill form](/images/kb/103000035071/PZSQm-gFBBXnncKsn0XB1cuAtYKJYIJ1PQ.jpeg)

![Scanning QR code to fill form](/images/kb/103000035071/dwQjAYO0BFY7mejJcJ5n41a2jPvwrEj_uw.jpeg)

The camera will open, ready to scan the QR code. 

![Scanning QR code to fill form](/images/kb/103000035071/IeqYm-XHNuUJ3yXFgZBZrdqfM5i8-fM8sA.png)

If there are multiple mappings, a pop-up will appear for you to choose one. 

![Scanning QR code to fill form](/images/kb/103000035071/uGwExS3MMBeZl1itxMt5Tn8ILP9sStWY8g.jpeg)

Once selected, the data will be inputted.

![Scanning QR code to fill form](/images/kb/103000035071/jYue6dOrQUolZHH_c1fNR7gwlZE_U9TKJQ.jpeg)

Check the accompanying GIF for a visual demonstration.

![Scanning QR code to fill form](/images/kb/103000035071/S2vAhdkFiSCGmsVG5KdpEMLyNeyGu3Hc6Q.gif)
