If you encounter any unusual behavior on the app, please report it to us. The RDrive support team will investigate, and it would be immensely helpful if you could export the project file and send it along with the report.

Here's how you can do it:

1.  Click the Sync button to synchronize (you can skip synchronization if not necessary) or use the Back button to go to the Project page.![How to export project (database + files) to send to SnagR?](/images/kb/103000035052/DoVIBSmeAdK5lO74JDB9B9GmdGOUk5NVqA.png)  
      
      
    
2.  Swipe right on the current project title to reveal the export option. You can either swipe all the way right or click the button to **Export** the database.![How to export project (database + files) to send to SnagR?](/images/kb/103000035052/_12UUv33JGHhzk_Q_L7kzvkgoVi2sGNPjw.jpeg)![How to export project (database + files) to send to SnagR?](/images/kb/103000035052/FqFk19kb4y7W6MzJ1ib1_d8ZLI8iwnDr6A.jpeg)  
      
      
      
      
    
3.  **OK** to confirm to start the export process.![How to export project (database + files) to send to SnagR?](/images/kb/103000035052/ZtIn4yfRZ2z5w37tagaS3bbsKV6lEBQ54A.jpeg)

Archiving...

![How to export project (database + files) to send to SnagR?](/images/kb/103000035052/80tMVDT4ncJK1CDE9knfdU_7BenIhd21EA.jpeg)

The app will initiate the archiving process, and a success message will appear upon completion. You can either click "Show file" to open and share it with us or click "OK" to close the dialogue.

<Info>
Please note that some Android devices may fail to open the file directly. In such cases, access the folder using the provided path to share the file with us.
</Info>
