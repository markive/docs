title: "What is the difference between the Download Project Modes?"
description: "In RDrive, there are different types of Download Project Modes for you to choose from when you first download a project."
---

  

In **RDrive**, there are different types of Download Project Modes for you to choose from when you first download a project. 

  

You should select the mode based on your circumstances and/or the internet connection environment of the project you are working on. 

  

Let's explore these options below.

  

  

![What is the difference between the Download Project Modes?](/images/kb/103000007092/1xveVIzSiRToiX0L8HtCb-gFrNxRamTHWA.png)

###   

### **Offline Mode (Default)**

**For unreliable or restricted mobile or Wi-fi connections**

**  
All drawings & images will be cached on this device for full offline access**

  

A project can contain large amounts of images (drawings, form page templates, issue & form photo field history, etc). If a user wants to have access to all images and conduct their work without reliable internet they will have to choose "**Offline Mode**".

  

This means that all images will be downloaded to the device whilst **synchronising**.

  

**Pro's:**

  

Not dependent on an internet connection once the project is synchronised

  

Images are always available to the user, and should load faster

  

**Con's:**

  

Takes longer to synchronise

  

Requires more storage space on the device

  

* * *

###   

### **Online Mode**

**For reliable mobile or Wi-fi connections.**

**  
Choose this option to reduce cached images and initial download size**

  

If a user just requires a quick/light access to a project and/or have access to a reliable internet connection they can use "**Online mode**".

  

This means that images will **NOT** be downloaded while synchronising. Instead, images will only be downloaded when the users try to access them whilst using the app (navigating to a specific drawing, accessing a specific issue, etc)

  

**Pro's:**

  

Takes less time to synchronise a project

  

Requires less storage space on the device

  

**Con's :**

  

Dependent on a (strong) internet connection

![What is the difference between the Download Project Modes?](/images/kb/103000007092/ID0RyMjRPOcqhW0W8iNCTj2qm5i5I0VrfQ.png)

###   

### For the "Online mode", there are 2 different sub modes.

###   

### Download project assets

  

**Synchronize base drawings and form template images are downloaded to the device to improve loading time.**

**  
Excluding the issue images.**

**  
Good for slow/intermittent connection speeds**.

  

"**Download project assets**" means that drawings and form page images are download whilst synchronising but that the rest of the images are lazy loaded. 

  

**(Please note that this is a hybrid mode, allowing users to navigate to drawings and filling in forms even when the internet connection is cut off as images are already downloaded)**.

  

  

### Lazy Load Project assets

  

**All images including drawings, form templates, and issue photos etc will be downloaded only when required.**

**  
Good for fast/consistent connection speeds.**

  

"**Lazy load project assets**" means that all images present in the project will be lazy loaded (loaded only when selected).

  

**(Please note that any loss of internet connection may cause the user not to be able to load the image when required and may prevent them from being able to complete their work eg. if the app cannot load a drawing image, it will not be easy for a user to place a pin on it).**
