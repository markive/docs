# How do I download the project on the mobile app?

(Mobile) Install the project on your device

Thanks for choosing RDrive!  
  
To download RDrive App on your device, please install RDrive from App Store or Play Store.

To add projects to your device, be sure you have **internet connectivity**. 

Your project and account should already be set up before you can download the project.  
  
Once the app is downloaded, please follow the below steps:

![How do I download project on the mobile app?](/images/kb/103000007089/nJJi7YSEtv9iWD_WmjWmMfFhVTM4DXtmjw.png)

Enter the Company URL, click **NEXT**.

_The Company URL is the first part of the URL used to access your domain. For example, if the full URL is "https://**snagr**.rdrive.io/123," the Company URL is "**snagr**." Please input "**snagr**" to log in via the app._  
  

Enter your registered email address and password, click **NEXT.**

![How do I download project on the mobile app?](/images/kb/103000007089/SzOohmouo2MnEBIX4XfRUeLikRtHoFzAmw.png)

<Info>
✨What's the QR code for?

Scan the QR code printed on the welcome email. This automatically fills in the project URL for you. Simply type in your username and password to proceed.
</Info>

![How do I download project on the mobile app?](/images/kb/103000007089/mxj1AzcVCxvMpYQSffworl1khAXd-Ekm4w.png)Next, You will see the project list of all projects you are involved.  
Click the **download button** next to the project and download it!

**![How do I download project on the mobile app?](/images/kb/103000007089/cTW_RjaB8UNe6E4xsZyTgC-bCR8r-wXkuQ.png)**

**![How do I download project on the mobile app?](/images/kb/103000007089/613ju1D2yOllCXAGI8ftgo3NmO_D7-iAcQ.png)**

**Select the [mode](https://snagr-support.freshdesk.com/en/support/solutions/articles/103000007092-what-is-the-difference-between-the-download-project-modes-) to download the project.**

**Then, you can now access the project when it is completed and downloaded!**
