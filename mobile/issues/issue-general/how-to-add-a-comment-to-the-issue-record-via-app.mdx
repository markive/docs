To communicate on an issue specifically, you can make use of the comment function.

Open the issue/record detail from the Plan viewer or Finder.

![How to add a comment to the issue/record via APP?](/images/kb/103000035179/ToD7oCEw0HL1Bp0xX8gLFa6jSFLlzjn5dw.jpeg)

Click the **Comment** icon**,** and click the "+" button.

![How to add a comment to the issue/record via APP?](/images/kb/103000035179/c-vujaIsFgmGU6XBCJFYIeXbanIfXXD7IA.jpeg)

![How to add a comment to the issue/record via APP?](/images/kb/103000035179/CQeN6TG5xFkMbsONUxsGNA2hTb0ZKDTQ5Q.jpeg)

Write down the comment and mention user(s) if needed.

![How to add a comment to the issue/record via APP?](/images/kb/103000035179/f_HbyjWlo2RrzT1EnsPcDzNozOHGl1iGGw.jpeg)

Click the **Comment** button to save.

![How to add a comment to the issue/record via APP?](/images/kb/103000035179/vHv-7VA6Z9-boOlMFBPmwv9S_JAYhyHbYQ.jpeg)

Done.  
You could edit and delete the un-sync comment.  
_⚠️ Once synced, the comment is unable to be edited and deleted._

![How to add a comment to the issue/record via APP?](/images/kb/103000035179/6bNaI06WCWtqrStkcfizcqYyOYSWJ3RzAg.jpeg)
