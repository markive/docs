### **Overview**

_How to raise an issue, defect or record using RDrive_

-   **Purpose:** How to raise an issue, defect or form against a location on the app and desktop
-   **Who It’s For:** \[General users, admins, project teams, etc.\]

<Note>
Prerequisites: Able to raise an issue, defect or record
</Note>

  
Step-by-Step Instructions - App

### ✅ Step 1: Accessing the Plan Viewer

1.  From the main menu in the app, select "View Plans" Under the Plans tab.![How to Raise an Issue, Defect, or Record](/images/kb/103000035182/6BHcBMqhwQhPnP-QPl30EGMveMRlYvYbHA.png)
2.  Navigate to the required drawing using the drilldown buttons as required.
3.  Once your required drawing or floor is open, you should now see blue "Location Pins"; all actions are raised against locations within a drawing. Click the blue pin required to get started raising actions to that location.![How to Raise an Issue, Defect, or Record](/images/kb/103000035182/kWan9dZTqJzSc1KbOlCZ_UtF1hJKc9h_Uw.png)

### ✅ Step 2: Raising Actions Against a Location

1.  Selecting a location will open a tab allowing you to add actions to this location. Select the "+" button in the top right.![How to Raise an Issue, Defect, or Record](/images/kb/103000035182/vt5q6x6yxa3Mz6CDqO0tKsk75MUUbYjz2Q.png)
2.  Select the required action from the appropriate subcategory, a defect or a form, for example.![How to Raise an Issue, Defect, or Record](/images/kb/103000035182/6Vlg9o48M7Y_H1KfbbHsdeiu2N3Wq3yHxQ.png)

### ✅ Step 3: Placing the Pin on the Drawing

1.  You can now place the pin against the location selected, drag or press where to place the pin and select "Place" once in the correct position.![How to Raise an Issue, Defect, or Record](/images/kb/103000035182/dazrj1vHYg5EV2zWak4dZ1Mp1wlr2qS7sw.png)
2.  You can zoom and adjust the drawing on screen by pinching two fingers on the screen to adjust size as required.

### ✅ Step 4: Enter the Action Information

1.  We can now fill out the action details. For defects, this will be categorising the issue with the option to add photos, for forms, this will be bespoke to the digital form process itself. Fields marked with a \* are mandatory to complete before moving on.
2.  Once all mandatory fields are completed, select "Save" in the bottom right. The defect or form will now be added against the location on the drawing.![How to Raise an Issue, Defect, or Record](/images/kb/103000035182/pOoy2CoMrJ44X8EKyFLgc1Oq9mZTtmcRfg.png)

## ****FAQs & Troubleshooting****

**Q: How do I raise a defect or form in RDrive?**  
**A:** Open the **Plan Viewer** (app or desktop), navigate to a drawing, and select a **location pin** or tap the **"+" button**. Choose an action (defect/form), place the pin, complete required fields (\*), and hit **"Save"**.

**Q: Can I reuse info from a previous defect or form?**  
**A:** Yes. On the app, select **"Yes"** when prompted to prepopulate from the last item. Or, tap the **pen icon** in "Add Defects" to copy from an older item. Adjust fields as needed before saving.

**Q: Should I use the pin or the "+" button to raise an issue?**  
**A:** Use a **pin** if it’s already on the drawing for that location. Use the **"+" button** to place a new pin manually. Both lead to the same action entry process.
