# **Overview**

**RPilot is RDrive's AI-powered assistant, designed to provide a simpler and more intelligent way to interact with RDrive data and functionality.**

  

Integrated directly with RDrive and its APIs, RPilot allows users to ask questions, investigate project information, extract and summarise data, navigate connected records and, where supported, carry out actions using natural, everyday language.

  

Unlike a standalone chatbot, RPilot works with the information and functionality available within the RDrive environment. Users don't necessarily need to know where information is stored before asking a question, RPilot can identify relevant records, work with the information contained within them and bring the answer back conversationally.

  

RPilot continues to evolve, with capabilities extending across **search and investigation, data extraction and analysis, navigation, multilingual interaction, automation and AI-assisted digitisation**.

  

The features and capabilities below provide an overview of how RPilot can be used and the value each capability can bring to RDrive users.

* * *

**Feature / Capability**

**What it means**

**Customer value**

**Natural-Language Interaction**

Users communicate with RPilot conversationally using everyday language rather than needing specific commands or knowing exactly where information sits in RDrive.

Makes RDrive information quicker and easier to access.

**RDrive-Aware AI**

RPilot works with RDrive data and supported functionality rather than behaving like a standalone general-purpose chatbot.

Provides responses and supported actions relevant to the user's RDrive environment.

**Intelligent Record Search & Investigation**

RPilot can interpret a user's question, search relevant project information and identify records containing the information being requested.

Reduces time spent manually searching through forms and records and helps users investigate information more efficiently.

**Cross-Record Data Extraction & Summarisation**

RPilot can retrieve information held across multiple relevant records and bring it together into a conversational response.

Allows users to answer project questions without opening and reviewing individual records one by one.

**Connected Record Discovery & Navigation**

RPilot can identify related or linked project information and provide access to the underlying RDrive records.

Makes it easier to understand relationships between project information and navigate directly to supporting records.

**Action-Based AI**

Where supported, RPilot can perform actions within RDrive rather than only providing an answer.

Reduces repetitive administration and the number of steps required to complete everyday activities.

**Conversational Analysis & Exploration**

Users can explore information through follow-up questions, progressively refining or investigating the results.

Makes project analysis more accessible without requiring users to repeatedly search or start again.

**Contextual Follow-Up**

RPilot can continue a conversation, allowing subsequent questions to build on the information already being discussed.

Allows users to progressively investigate a question or dataset in a more natural way.

**Multilingual Interaction**

Users can interact with RPilot in different languages, including asking questions about project information recorded in another language.

Supports international organisations and multilingual project teams.

**Voice Input**

Users can speak their request rather than typing it.

Provides a faster and more natural way to interact with RPilot.

**AI-Assisted Form Digitisation**

Existing forms and documents can be processed to assist with creating structured digital RDrive forms.

Reduces the effort involved in converting existing processes and documentation into RDrive.

**Embedded RDrive Experience**

RPilot is accessed directly from within RDrive.

Users can work with AI alongside their project information without moving data into a separate application.

**API-Level Integration**

RPilot is built on top of RDrive APIs, allowing deeper interaction with the RDrive platform.

Enables RPilot to work with RDrive information and supported functionality rather than simply searching static content.

**Configuration Assistance** _(Developing)_

RPilot has the potential to assist with areas of RDrive configuration, such as interrogating and managing tags and related settings.

Could simplify administration and configuration, particularly across larger RDrive environments.
